Consider three linear equations in four unknowns, with rational coefficients and a right-hand side $(y_1,y_2,y_3)$ that is not yet fixed:

$$ \begin{aligned} 2x_3+2x_4&=y_1,\\ 2x_1+4x_2+x_3+7x_4&=y_2,\\ 2x_1+4x_2+3x_3+9x_4&=y_3. \end{aligned} $$

Call this system (R), the chapter's running example. It is an original construction, built so that every phenomenon of this chapter appears in it. Two questions come with any such system. For which right-hand sides does a solution exist? When one exists, what are all the solutions? School elimination answers both questions by replacing the system with a simpler one, step by step. Every step must keep the set of solutions exactly the same. If a step loses a solution, the method can report a false "no solution". If a step gains a solution, the method can report a false answer.

The second failure is easy to cause. Take $y_1=y_2=y_3=0$ and replace the first two equations, at the same time, by their sum. Each new equation is a true consequence of the old ones, since a sum of true equations is true. The new system is $2x_1+4x_2+3x_3+9x_4=0$, written three times. The vector $(0,0,3,-1)$ satisfies it. It does not satisfy the original first equation, because $2\cdot 3+2\cdot(-1)=4\neq 0$. The replacement gained solutions, so it lost information.

This chapter identifies which replacements are safe and proves that they are safe. The answer has four parts. Elimination needs the arithmetic of a field (Section 1). A replacement keeps the solutions when each system can be recovered from the other by linear combinations (Section 5). Three elementary row operations have this property because each one has an inverse of the same kind (Sections 7 and 8). Finally, these operations always reach a row-reduced matrix, whose solutions can be read off (Sections 10 and 11). At the end we return to (R) and find the condition $y_3=y_1+y_2$ for a solution and the complete solution set.

1. Fields: the arithmetic that elimination needs 04:07

Elimination adds equations, multiplies them by constants, and divides by a nonzero coefficient. The numbers that appear as coefficients must therefore permit these four operations and obey the usual algebraic laws. A field is the precise list of these laws.

Definition 1.1 (field). A field is a set $F$ with two binary operations, addition $(x,y)\mapsto x+y$ and multiplication $(x,y)\mapsto xy$, that satisfy the following axioms for all $x,y,z\in F$.

  • Addition: $x+y=y+x$; $(x+y)+z=x+(y+z)$; there is an element $0\in F$ with $x+0=x$; for each $x$ there is an element $-x\in F$ with $x+(-x)=0$.
  • Multiplication: $xy=yx$; $(xy)z=x(yz)$; there is an element $1\in F$, with $1\neq 0$, such that $1x=x$; for each $x\neq 0$ there is an element $x^{-1}\in F$ with $xx^{-1}=1$.
  • Distributivity: $x(y+z)=xy+xz$.

A set with one associative operation that has an identity element and an inverse for each element is a group; a group whose operation is also commutative is an abelian group. In this language $(F,+)$ is an abelian group, and the set $F\setminus\{0\}$ of nonzero elements is an abelian group under multiplication. The multiplicative statement excludes $0$ on purpose: no element $z$ satisfies $0z=1$, as Lemma 1.2 shows. The requirement $1\neq 0$ excludes the one-element set $\{0\}$. We write $x-y$ for $x+(-y)$ and $x/y$ for $xy^{-1}$ when $y\neq 0$. Closure, which says that $x+y$ and $xy$ lie in $F$, is part of the word "binary operation on $F$".

The rational numbers $\mathbb{Q}$, the real numbers $\mathbb{R}$, and the complex numbers $\mathbb{C}$ are fields under their usual operations. A field need not be infinite. The set $\mathbb{F}_2=\{0,1\}$ with the operations

$$ 0+0=0,\quad 0+1=1+0=1,\quad 1+1=0,\qquad 0\cdot 0=0\cdot 1=1\cdot 0=0,\quad 1\cdot 1=1 $$

is a field. These are the integers modulo 2. In $\mathbb{F}_2$ we have $-1=1$ and $1+1=0$. More generally, for a prime $p$ the integers modulo $p$ form a field $\mathbb{F}_p$. To see that a nonzero class $a$ has an inverse, note that the map $b\mapsto ab$ on the $p$ classes is injective: if $p$ divides $a(b-b')$ and does not divide $a$, then it divides $b-b'$ because $p$ is prime. An injective map of a finite set to itself is surjective, so some $b$ has $ab=1$. The laboratory computes this inverse as $a^{p-2}$, which is correct by Fermat's little theorem, the statement that $a^{p-1}=1$ for every nonzero class $a$. Two non-examples mark the boundary. The integers $\mathbb{Z}$ satisfy every axiom except the existence of multiplicative inverses: no integer $z$ has $2z=1$. The integers modulo $6$ also fail, because $2\cdot 3=0$ although $2\neq 0$ and $3\neq 0$; Lemma 1.2(c) shows that this cannot happen in a field.

Lemma 1.2. Let $F$ be a field and let $x,y\in F$. Then (a) $0x=0$; (b) $(-1)x=-x$; (c) if $xy=0$, then $x=0$ or $y=0$.

Proof. (a) Distributivity gives $0x=(0+0)x=0x+0x$. Add $-(0x)$ to both sides to obtain $0=0x$. (b) By distributivity and (a), $x+(-1)x=(1+(-1))x=0x=0$. So $(-1)x$ is an additive inverse of $x$. Additive inverses are unique: if $x+u=0$ and $x+w=0$, then $u=u+(x+w)=(u+x)+w=w$. Hence $(-1)x=-x$. (c) Suppose $xy=0$ and $x\neq 0$. Multiply by $x^{-1}$ and use (a): $y=x^{-1}(xy)=x^{-1}0=0$. $\square$

Part (c) is the hinge for elimination. Multiplying an equation by $c\neq 0$ can be undone by multiplying by $c^{-1}$. Multiplying by $c=0$ cannot be undone: it turns every equation into $0=0$ and so destroys the information that the equation carried. Part (a) is the reason for this destruction.

Definition 1.3 (subfield). Let $F$ be a field. A subset $K\subseteq F$ is a subfield of $F$ if $K$, with the addition and multiplication of $F$ restricted to $K$, is a field.

The phrase "the operations of $F$" is essential. The set $\{0,1\}$ is a subset of $\mathbb{R}$, and it is a field under the operations of $\mathbb{F}_2$, but it is not a subfield of $\mathbb{R}$: in $\mathbb{R}$ the sum $1+1=2$ is not in $\{0,1\}$. To test a subset, one need not check every axiom. If $K$ contains $1$, and $K$ is closed under subtraction and under division by its nonzero elements, then $K$ is a subfield. Indeed, $0=1-1\in K$, $-x=0-x\in K$, $x^{-1}=1/x\in K$ for $x\neq 0$, $x+y=x-(-y)\in K$, and $xy=x/y^{-1}\in K$ for $y\neq 0$ (and $x0=0\in K$). The equational axioms hold in $K$ because they hold in $F$. With this test, $\mathbb{Q}$ is a subfield of $\mathbb{R}$, and $\mathbb{R}$ is a subfield of $\mathbb{C}$. A less familiar example is $\mathbb{Q}(\sqrt2)=\{a+b\sqrt2: a,b\in\mathbb{Q}\}\subseteq\mathbb{R}$. It is closed under subtraction. If $a+b\sqrt2\neq 0$, then $a^2-2b^2\neq 0$ because $\sqrt2$ is irrational, and $(a+b\sqrt2)^{-1}=(a-b\sqrt2)/(a^2-2b^2)$, which lies in the set. So the set is also closed under division.

Subfields matter for linear systems because elimination uses only the four field operations on the coefficients. If every coefficient lies in a subfield $K$ of $F$, every number produced by the procedure of Section 11 also lies in $K$. The running example (R) has rational coefficients, so all its computations stay in $\mathbb{Q}$, even if we later regard the unknowns as real or complex.

The field also changes answers. Over $\mathbb{Q}$ the system $x_1+x_2=1$, $x_1-x_2=0$ has the unique solution $(1/2,1/2)$. Over $\mathbb{F}_2$, $-1=1$, so the two equations become $x_1+x_2=1$ and $x_1+x_2=0$, and no solution exists. Exercise 4 locates the step that fails. From now on, $F$ denotes an arbitrary field unless a statement names a specific one. The same convention is used by Hoffman and Kunze (Chapter 1).

2. Systems of linear equations and their solution sets 15:54

Let $m$ and $n$ be positive integers. A system of $m$ linear equations in $n$ unknowns over $F$ is a list of equations

$$ \begin{aligned} A_{11}x_1+A_{12}x_2+\cdots+A_{1n}x_n&=y_1,\\ A_{21}x_1+A_{22}x_2+\cdots+A_{2n}x_n&=y_2,\\ &\ \,\vdots\\ A_{m1}x_1+A_{m2}x_2+\cdots+A_{mn}x_n&=y_m, \end{aligned} $$

in which the coefficients $A_{ij}$ and the right-hand sides $y_i$ are given elements of $F$, for $1\le i\le m$ and $1\le j\le n$. We call this system (S). The first index $i$ names the equation and the second index $j$ names the unknown. A solution of (S) is an $n$-tuple $(x_1,\dots,x_n)\in F^n$ that satisfies all $m$ equations at once. The solution set of (S) is the set of all its solutions; it can be empty. The system is homogeneous if $y_1=\cdots=y_m=0$ and nonhomogeneous otherwise. A system with at least one solution is consistent; a system with none is inconsistent.

A homogeneous system always has the trivial solution $(0,\dots,0)$, so the existence question arises only for nonhomogeneous systems. The question that remains for a homogeneous system is whether nonzero solutions exist. Replacing every $y_i$ in (S) by $0$ gives the associated homogeneous system.

We add $n$-tuples and multiply them by scalars entrywise: $(x_j)+(x_j')=(x_j+x_j')$ and $c(x_j)=(cx_j)$. With these operations the following structure theorem holds. It is the first appearance of a theme of the whole book: solution sets of linear problems carry linear structure.

Theorem 2.1 (structure of solution sets). Let (S) be a system over a field $F$.

  1. If $X$ and $X'$ solve the associated homogeneous system and $c\in F$, then $cX+X'$ also solves it.
  2. If $X_p$ is one solution of (S), then $X$ solves (S) if and only if $X-X_p$ solves the associated homogeneous system.
  3. If (S) has two distinct solutions $X_0\neq X_1$, then $X_0+t(X_1-X_0)$ is a solution for every $t\in F$, and different values of $t$ give different solutions. Consequently (S) has at least as many solutions as $F$ has elements.

Proof. Write $\ell_i(X)=A_{i1}x_1+\cdots+A_{in}x_n$ for the left side of equation $i$. Distributivity and commutativity give $\ell_i(cX+X')=c\,\ell_i(X)+\ell_i(X')$ for all tuples $X,X'$ and scalars $c$. For part 1, if $\ell_i(X)=\ell_i(X')=0$ for every $i$, then $\ell_i(cX+X')=c0+0=0$. For part 2, $\ell_i(X-X_p)=\ell_i(X)-y_i$, which is $0$ for every $i$ exactly when $\ell_i(X)=y_i$ for every $i$. For part 3, part 2 shows that $D=X_1-X_0$ solves the associated homogeneous system, part 1 shows that $tD$ does, and part 2 again shows that $X_0+tD$ solves (S). If $X_0+tD=X_0+t'D$, then $(t-t')D=0$. Some entry $d_j$ of $D$ is nonzero, and $(t-t')d_j=0$ forces $t=t'$ by Lemma 1.2(c). $\square$

Over an infinite field such as $\mathbb{Q}$, $\mathbb{R}$ or $\mathbb{C}$, part 3 gives the familiar trichotomy: a system has no solution, exactly one, or infinitely many. Over a finite field the third case changes. The single equation $x_1+x_2=1$ over $\mathbb{F}_2$ has exactly the two solutions $(1,0)$ and $(0,1)$, which is the bound $|\mathbb{F}_2|=2$ of part 3 with equality. "Infinitely many" is therefore a statement about the field, not about linear systems in general.

For (R), part 2 says that once we know one solution for a given right-hand side, the full solution set is that solution plus all solutions of the homogeneous system with $y_1=y_2=y_3=0$. Section 11 finds both pieces.

3. The row picture: each equation is a line or a plane 18:39

Over $\mathbb{R}$ with $n=2$, the solutions of one equation $a_1x_1+a_2x_2=b$ with $(a_1,a_2)\neq(0,0)$ form a line in the $(x_1,x_2)$-plane. A solution of a system of two such equations is a point on both lines. Take

$$ 2x_1+x_2=4,\qquad x_1-2x_2=-3. $$

The first line $L_1$ meets the axes at $(2,0)$ and $(0,4)$. The second line $L_2$ meets them at $(-3,0)$ and $(0,3/2)$. Subtract twice the second equation from the first: $5x_2=10$, so $x_2=2$, and then $x_1=-3+2x_2=1$. The lines cross at $(1,2)$. Check: $2\cdot1+2=4$ and $1-2\cdot2=-3$. If the lines are parallel and distinct, there is no common point. If they coincide, every point of the line is a solution. The following theorem turns these pictures into a statement that holds over every field and gives the test for each case.

Theorem 3.1 (two equations in two unknowns). Let $F$ be a field. Consider $a_1x_1+a_2x_2=b_1$ and $c_1x_1+c_2x_2=b_2$ with $(a_1,a_2)\neq(0,0)$ and $(c_1,c_2)\neq(0,0)$, and put $\Delta=a_1c_2-a_2c_1$.

  1. If $\Delta\neq 0$, the system has exactly one solution, $x_1=(b_1c_2-a_2b_2)/\Delta$ and $x_2=(a_1b_2-c_1b_1)/\Delta$.
  2. If $\Delta=0$, there is a $\lambda\neq 0$ in $F$ with $(c_1,c_2)=\lambda(a_1,a_2)$. The system is then consistent if and only if $b_2=\lambda b_1$, and in that case the second equation is $\lambda$ times the first.

Proof. Multiply the first equation by $c_2$ and the second by $a_2$, and subtract: $\Delta x_1=b_1c_2-a_2b_2$. Multiply the second by $a_1$ and the first by $c_1$, and subtract: $\Delta x_2=a_1b_2-c_1b_1$. Every solution satisfies both derived equations. If $\Delta\neq0$, the derived equations determine $(x_1,x_2)$ uniquely, so there is at most one solution. Substitution shows that the displayed pair does satisfy both original equations; for example, $a_1(b_1c_2-a_2b_2)+a_2(a_1b_2-c_1b_1)=b_1(a_1c_2-a_2c_1)=b_1\Delta$. This proves part 1. For part 2, suppose $\Delta=0$ and $a_1\neq 0$. Put $\lambda=c_1/a_1$. Then $c_2=a_2c_1/a_1=\lambda a_2$ because $a_1c_2=a_2c_1$. If $a_1=0$, then $a_2\neq0$, and $\lambda=c_2/a_2$ works in the same way. Here $\lambda\neq 0$ because $(c_1,c_2)\neq(0,0)$. Subtracting $\lambda$ times the first equation from the second gives $0=b_2-\lambda b_1$. If $b_2\neq\lambda b_1$, no solution exists. If $b_2=\lambda b_1$, the second equation is $\lambda$ times the first and has the same solutions, which form a line. $\square$

For the example, $\Delta=2(-2)-1\cdot1=-5$, and part 1 gives $x_1=(4(-2)-1(-3))/(-5)=1$ and $x_2=(2(-3)-1\cdot4)/(-5)=2$. Over $\mathbb{R}$, $\Delta=0$ says exactly that the normal vectors $(a_1,a_2)$ and $(c_1,c_2)$ are proportional, which is the algebraic form of "parallel".

With three unknowns over $\mathbb{R}$, an equation with a nonzero coefficient row defines a plane. For example, $x_1+x_3=2$ is a plane that contains every line parallel to the $x_2$-axis through one of its points, and $x_1+2x_2=3$ is a plane that contains the lines parallel to the $x_3$-axis. It is tempting to extend the two-line picture: "if no two of the planes are parallel, the system is consistent". This is false. The planes

$$ x_1=0,\qquad x_2=0,\qquad x_1+x_2=1 $$

have pairwise non-proportional normal vectors $(1,0,0)$, $(0,1,0)$ and $(1,1,0)$, so no two are parallel. The first two equations force $x_1=x_2=0$, and then the third reads $0=1$. Each pair of planes meets in a line parallel to the $x_3$-axis, and the three lines are parallel to one another, like the edges of a triangular prism. Consistency is a property of all equations together, not of pairs of them. A test that sees all equations together is what elimination supplies, and the laboratory confirms that the procedure of Section 11 reduces this system to the equation $0=1$.

4. The column picture: solving means forming a combination 22:10

The same system can be read by columns instead of rows. Write the coefficients of $x_j$ as a column $a^{(j)}=(A_{1j},\dots,A_{mj})$ in $F^m$, and the right-hand side as $Y=(y_1,\dots,y_m)$. Then (S) says exactly

$$ x_1a^{(1)}+x_2a^{(2)}+\cdots+x_na^{(n)}=Y. $$

An expression $c_1v_1+\cdots+c_kv_k$ with scalars $c_i\in F$ and vectors $v_i\in F^m$ is a linear combination of $v_1,\dots,v_k$. So the system asks whether $Y$ is a linear combination of the columns, and a solution is a list of weights that produces $Y$. For the two-line example, with $u=(2,1)$ and $v=(1,-2)$,

$$ 1\cdot\begin{pmatrix}2\\1\end{pmatrix}+2\cdot\begin{pmatrix}1\\-2\end{pmatrix}=\begin{pmatrix}4\\-3\end{pmatrix}. $$

Geometrically, one step along $u$ followed by two steps along $v$ lands at $(4,-3)$.

The column picture explains the existence question for (R). Its columns are $a^{(1)}=(0,2,2)$, $a^{(2)}=(0,4,4)$, $a^{(3)}=(2,1,3)$ and $a^{(4)}=(2,7,9)$. Two relations hold among them: $a^{(2)}=2a^{(1)}$ and $a^{(4)}=3a^{(1)}+a^{(3)}$. Collecting terms gives

$$ x_1a^{(1)}+x_2a^{(2)}+x_3a^{(3)}+x_4a^{(4)}=(x_1+2x_2+3x_4)\,a^{(1)}+(x_3+x_4)\,a^{(3)}. $$

So the attainable right-hand sides are exactly the combinations $s\,a^{(1)}+t\,a^{(3)}=(2t,\,2s+t,\,2s+3t)$ with $s,t\in\mathbb{Q}$. Every such vector satisfies $y_3-y_1-y_2=(2s+3t)-2t-(2s+t)=0$. Conversely, if $y_3=y_1+y_2$, put $t=y_1/2$ and $s=(y_2-y_1/2)/2$. Then $2t=y_1$, $2s+t=y_2$, and $2s+3t=y_2+y_1=y_3$. Hence (R) is consistent if and only if $y_3=y_1+y_2$. For $Y=(2,9,11)$ it is consistent; for $Y=(2,9,12)$ it is not.

This argument has a weakness: the two column relations were found by inspection. A method that finds such relations for every system is the purpose of Sections 5 to 11. Note also that a column relation is itself a solution of a homogeneous system. The relation $a^{(2)}=2a^{(1)}$ says that $(2,-1,0,0)$ solves (R) with $Y=0$, and $a^{(4)}=3a^{(1)}+a^{(3)}$ says the same of $(3,0,1,-1)$. The row picture and the column picture describe one object.

5. Linear combinations of equations and equivalent systems 27:35

Elimination creates new equations from old ones. Choose scalars $c_1,\dots,c_m\in F$, multiply equation $i$ of (S) by $c_i$, and add. The result is the equation

$$ \Big(\sum_{i=1}^m c_iA_{i1}\Big)x_1+\cdots+\Big(\sum_{i=1}^m c_iA_{in}\Big)x_n=\sum_{i=1}^m c_iy_i, $$

called a linear combination of the equations of (S). The scalars may be any elements of $F$, including $0$; the choice $c_1=c$, $c_2=\cdots=c_m=0$ gives the single equation multiplied by $c$. It helps to store an equation as its row of $n+1$ numbers $(A_{i1},\dots,A_{in}\mid y_i)\in F^{n+1}$. In this form a linear combination of equations is a linear combination of rows.

Lemma 5.1. Every solution of (S) satisfies every linear combination of the equations of (S).

Proof. Let $X$ be a solution, so $\ell_i(X)=y_i$ for all $i$, with $\ell_i$ as in the proof of Theorem 2.1. The left side of the combination, evaluated at $X$, is $\sum_j\big(\sum_ic_iA_{ij}\big)x_j=\sum_ic_i\big(\sum_jA_{ij}x_j\big)=\sum_ic_i\ell_i(X)=\sum_ic_iy_i$, which is its right side. The exchange of the two finite sums uses only commutativity, associativity and distributivity in $F$. $\square$

Lemma 5.1 is one direction only. It says that the solution set can only grow when we pass to combinations. The opening failure is an instance: the new equations were combinations of the old ones, and the solution set grew. To keep it equal we need the passage to work in both directions.

Definition 5.2 (equivalent systems). Two systems of linear equations in the same unknowns $x_1,\dots,x_n$ over $F$ are equivalent if each equation of each system is a linear combination of the equations of the other system.

Theorem 5.3. Equivalent systems of linear equations have exactly the same solutions.

Proof. Let (S) and (S') be equivalent. Every equation of (S') is a combination of the equations of (S), so by Lemma 5.1 every solution of (S) solves each equation of (S'), and hence solves (S'). The same argument with the roles exchanged shows that every solution of (S') solves (S). The two solution sets contain each other, so they are equal. $\square$

The hinge is the word "each" in Definition 5.2, applied in both directions. A one-sided version of the definition proves only one inclusion. In the opening example, the replaced homogeneous system consists of three copies of $2x_1+4x_2+3x_3+9x_4=0$. Any combination of its equations is a multiple $c(2x_1+4x_2+3x_3+9x_4)=0$. The original first equation $2x_3+2x_4=0$ is not of this form, because a multiple with zero $x_1$-coefficient has $c=0$ and then zero $x_3$-coefficient too. So the systems are not equivalent, and the witness $(0,0,3,-1)$ shows that the solution sets differ.

Proposition 5.4. Equivalence of systems in $n$ unknowns over $F$ is an equivalence relation: it is reflexive, symmetric and transitive.

Proof. Each equation of a system is a combination of that system's equations (weight $1$ on itself and $0$ elsewhere), which gives reflexivity. Symmetry holds because Definition 5.2 is symmetric in the two systems. For transitivity, store equations as rows. Suppose each row $g_k$ of a third system is $\sum_i d_{ki}f_i$, where the $f_i$ are the rows of a second system, and each $f_i=\sum_j c_{ij}e_j$, where the $e_j$ are the rows of the first. Then $g_k=\sum_j\big(\sum_i d_{ki}c_{ij}\big)e_j$, a combination of the $e_j$. The same computation runs in the reverse direction. $\square$

The converse of Theorem 5.3 is false. Over any field, with one unknown, the system $\{x_1=0,\ x_1=1\}$ and the system $\{0x_1=1\}$ both have the empty solution set. Every combination of the second system has the form $0x_1=c$, so the equation $x_1=0$ is not such a combination, and the systems are not equivalent. Equal solution sets therefore do not certify equivalence. The safe direction, and the one elimination uses, is from equivalence to equal solution sets.

6. The matrix form of a system 03:10

Writing out $x_1,\dots,x_n$ in every equation repeats information. All that distinguishes (S) from another system with the same unknowns is the array of coefficients and the list of right-hand sides.

An $m\times n$ matrix over $F$ is a function $A$ that assigns an element $A_{ij}\in F$ to each pair $(i,j)$ with $1\le i\le m$ and $1\le j\le n$. We display it as a rectangle with $m$ rows and $n$ columns; $A_{ij}$ is the entry in row $i$ and column $j$. The set of all such matrices is $F^{m\times n}$. Elements of $F^n$ are columns, that is, $n\times1$ matrices. The coefficient matrix of (S) is $A=(A_{ij})\in F^{m\times n}$. Its unknown and right-hand side are the columns

$$ X=\begin{pmatrix}x_1\\ \vdots\\ x_n\end{pmatrix}\in F^n,\qquad Y=\begin{pmatrix}y_1\\ \vdots\\ y_m\end{pmatrix}\in F^m. $$

Definition 6.1 (matrix product). For $B\in F^{m\times p}$ and $C\in F^{p\times n}$, the product $BC\in F^{m\times n}$ has entries $(BC)_{ij}=\sum_{k=1}^pB_{ik}C_{kj}$.

With $C=X$ and $p=n$, entry $i$ of $AX$ is $A_{i1}x_1+\cdots+A_{in}x_n$. So (S) is the single matrix equation $AX=Y$, and its homogeneous form is $AX=0$. The augmented matrix $[A\mid Y]\in F^{m\times(n+1)}$ appends $Y$ as a last column. Row $i$ of $[A\mid Y]$ is the stored form of equation $i$. For (R),

$$ A=\begin{pmatrix}0&0&2&2\\2&4&1&7\\2&4&3&9\end{pmatrix},\qquad [A\mid Y]=\left(\begin{array}{cccc|c}0&0&2&2&y_1\\2&4&1&7&y_2\\2&4&3&9&y_3\end{array}\right). $$

Two facts about products carry the rest of the chapter. Write $\beta_k$ for row $k$ of $C$, a $1\times n$ matrix.

Lemma 6.2. (a) Row $i$ of $BC$ is $\sum_{k=1}^pB_{ik}\beta_k$: a linear combination of the rows of $C$, with weights taken from row $i$ of $B$. (b) Whenever the sizes allow the products, $(BC)D=B(CD)$.

Proof. (a) Entry $j$ of $\sum_kB_{ik}\beta_k$ is $\sum_kB_{ik}C_{kj}=(BC)_{ij}$. (b) For $D\in F^{n\times q}$, both $((BC)D)_{ij}$ and $(B(CD))_{ij}$ equal the double sum $\sum_{k}\sum_{l}B_{ik}C_{kl}D_{lj}$; the two sides differ only in the order of the finite summation. $\square$

Part (a) is the link between Section 5 and matrices. If $P\in F^{m\times m}$, then each row of $P[A\mid Y]=[PA\mid PY]$ is a combination of the rows of $[A\mid Y]$. So every equation of the system $(PA)X=PY$ is a linear combination of the equations of $AX=Y$. Part (b) lets us write $P(AX)=(PA)X$ without brackets. The general theory of the matrix product, including its link with composition of maps, belongs to Chapter 9; this chapter uses only Lemma 6.2.

7. Elementary row operations and their inverses 04:46

Elimination uses three kinds of steps. Each step replaces a matrix by a new matrix of the same size. We state them for a matrix $A\in F^{m\times n}$; for a system they are applied to the augmented matrix $[A\mid Y]$, so that the right-hand side changes with the coefficients.

Definition 7.1 (elementary row operations). Let $r,s\in\{1,\dots,m\}$ and $c\in F$. An elementary row operation is a function $e:F^{m\times n}\to F^{m\times n}$ of one of three types.

  1. Scaling, for $c\neq 0$: multiply row $r$ by $c$. In entries, $e(A)_{ij}=A_{ij}$ for $i\neq r$ and $e(A)_{rj}=cA_{rj}$.
  2. Replacement, for $r\neq s$ and any $c$: add $c$ times row $s$ to row $r$. In entries, $e(A)_{ij}=A_{ij}$ for $i\neq r$ and $e(A)_{rj}=A_{rj}+cA_{sj}$.
  3. Interchange, for $r\neq s$: exchange rows $r$ and $s$. In entries, $e(A)_{ij}=A_{ij}$ for $i\notin\{r,s\}$, $e(A)_{rj}=A_{sj}$ and $e(A)_{sj}=A_{rj}$.

Each formula holds for every column index $1\le j\le n$. We write $R_r\leftarrow cR_r$, $R_r\leftarrow R_r+cR_s$ and $R_r\leftrightarrow R_s$ for the three types.

The side conditions $c\neq 0$ in type 1 and $r\neq s$ in type 2 are not decoration. Without them the operations can destroy information. Scaling by $0$ replaces a row by zeros. The "replacement" $R_r\leftarrow R_r+cR_r$ with $r=s$ is scaling by $1+c$, and for $c=-1$ it is again scaling by $0$. The faulty step of the opening changed two rows at the same time. Performed in sequence, its first half $R_1\leftarrow R_1+R_2$ is elementary, but its second half then sets row 2 equal to the new row 1. That is $R_2\leftarrow 0R_2+R_1$, which is none of the three types.

Theorem 7.2 (inverse operations). For each elementary row operation $e$ there is an elementary row operation $e_1$ of the same type with $e_1(e(A))=e(e_1(A))=A$ for every $A\in F^{m\times n}$.

Proof. For type 1 with constant $c\neq0$, let $e_1$ multiply row $r$ by $c^{-1}$; it is an elementary operation because $c^{-1}\neq 0$, and $c^{-1}(cA_{rj})=A_{rj}$. For type 2, let $e_1$ be $R_r\leftarrow R_r-cR_s$. Because $r\neq s$, the operation $e$ does not change row $s$. So after $e$, row $r$ is $A_{rj}+cA_{sj}$, and $e_1$ subtracts $c$ times the same row $s$, which returns $A_{rj}$. The other order is the same computation with $-c$ in place of $c$. For type 3, let $e_1=e$; exchanging two rows twice restores them. $\square$

The hinge in the type-2 case is the sentence "$e$ does not change row $s$". The inverse must subtract the same multiple of the same row that $e$ added. That is possible only if row $s$ still holds its old value, which is why $r\neq s$ is required.

8. Elementary matrices 09:42

An elementary row operation is a function on matrices. Lemma 6.2 shows that left multiplication by a fixed matrix is also such a function. The next theorem shows that every elementary operation is a left multiplication, so that a sequence of operations can be recorded as one matrix.

Definition 8.1. An $m\times m$ matrix is an elementary matrix if it equals $e(I)$ for some elementary row operation $e$, where $I$ is the $m\times m$ identity matrix ($I_{ii}=1$, and $I_{ij}=0$ for $i\neq j$).

Theorem 8.2. Let $e$ be an elementary row operation on matrices with $m$ rows, and let $E=e(I)$. Then $e(A)=EA$ for every $A\in F^{m\times n}$. Moreover $E$ is invertible: with $e_1$ as in Theorem 7.2 and $E_1=e_1(I)$, we have $E_1E=EE_1=I$.

Proof. Let $\alpha_k$ denote row $k$ of $A$, and let $\varepsilon_k$ denote row $k$ of $I$, which has $1$ in position $k$ and $0$ elsewhere. By Lemma 6.2(a), row $i$ of $EA$ is $\sum_kE_{ik}\alpha_k$. If row $i$ of $E$ equals $\varepsilon_i$, then row $i$ of $EA$ is $\alpha_i$. This settles every row that $e$ does not change. For the changed rows: in type 1, row $r$ of $E$ is $c\varepsilon_r$, so row $r$ of $EA$ is $c\alpha_r$; in type 2, row $r$ of $E$ is $\varepsilon_r+c\varepsilon_s$, so row $r$ of $EA$ is $\alpha_r+c\alpha_s$; in type 3, rows $r$ and $s$ of $E$ are $\varepsilon_s$ and $\varepsilon_r$, so rows $r$ and $s$ of $EA$ are $\alpha_s$ and $\alpha_r$. In each case $EA=e(A)$. For invertibility, apply the first part twice and use Theorem 7.2: $E_1E=E_1e(I)=e_1(e(I))=I$, and $EE_1=e(e_1(I))=I$. $\square$

For $m=3$, the operation "multiply row 2 by $c\neq0$" has the elementary matrix $E_1$ below, and its inverse operation "multiply row 2 by $1/c$" has $E_2$:

$$ E_1=\begin{pmatrix}1&0&0\\0&c&0\\0&0&1\end{pmatrix},\qquad E_2=\begin{pmatrix}1&0&0\\0&1/c&0\\0&0&1\end{pmatrix},\qquad E_2E_1=I. $$

So for a homogeneous system $AX=0$ with $A\in F^{3\times4}$, the system $E_1AX=0$ has the second equation multiplied by $c$, and $E_2(E_1A)=A$ recovers the original. The replacement $R_3\leftarrow R_3+cR_1$ has the identity matrix with $c$ added in position $(3,1)$. The interchange $R_1\leftrightarrow R_2$ has the identity with its first two rows exchanged.

Theorem 8.2 converts a sequence of operations into a product. If $B=e_k(\cdots e_2(e_1(A))\cdots)$ and $E_j=e_j(I)$, then by Lemma 6.2(b)

$$ B=E_k\cdots E_2E_1A=PA,\qquad P=E_k\cdots E_2E_1, $$

and $P$ is invertible with $P^{-1}=E_1^{-1}E_2^{-1}\cdots E_k^{-1}$. The matrix $P$ records the entire elimination.

9. Row equivalence preserves solutions 14:48

Definition 9.1 (row equivalence). Two matrices $A,B\in F^{m\times n}$ are row-equivalent if $B$ can be obtained from $A$ by a finite sequence of elementary row operations.

By Theorem 7.2 the reversed sequence of inverse operations takes $B$ back to $A$, so the relation is symmetric. It is reflexive (scale any row by $1$) and transitive (concatenate the sequences). Exercise 1 proves the matrix form: $A$ and $B$ are row-equivalent exactly when $B=PA$ for a product $P$ of elementary matrices. The word "row" matters. Later chapters call $A$ and $B$ equivalent when $B=PAQ$ with $P$ and $Q$ invertible; that relation also allows column operations, which change solution sets (Exercise 5). We write "row-equivalent" for the relation of this section throughout.

Theorem 9.2. Let $A,B\in F^{m\times n}$ and $Y,Z\in F^m$. If the augmented matrices $[A\mid Y]$ and $[B\mid Z]$ are row-equivalent, then the systems $AX=Y$ and $BX=Z$ have exactly the same solutions. In particular, if $A$ and $B$ are row-equivalent, then $AX=0$ and $BX=0$ have exactly the same solutions.

Proof. By transitivity of equality of solution sets it suffices to treat one operation, so let $[B\mid Z]=e([A\mid Y])$ for a single elementary row operation $e$. By Theorem 8.2, $[B\mid Z]=E[A\mid Y]$ with $E=e(I)$. By Lemma 6.2(a), every row of $[B\mid Z]$ is a linear combination of rows of $[A\mid Y]$; that is, every equation of $BX=Z$ is a combination of the equations of $AX=Y$. By Theorem 7.2, $[A\mid Y]=e_1([B\mid Z])=E_1[B\mid Z]$, so every equation of $AX=Y$ is a combination of the equations of $BX=Z$. The two systems are therefore equivalent in the sense of Definition 5.2, and Theorem 5.3 gives equal solution sets. For a finite sequence, apply this to each step in turn. The homogeneous statement is the case $Y=Z=0$, because every elementary operation maps a zero column to a zero column. $\square$

The proof needs both halves. The first half alone is Lemma 5.1 and gives only "every old solution is a new solution". The second half, which rests on the inverse operation, gives "every new solution is an old solution". The opening example failed exactly the second half.

The matrix form of the theorem is a two-line computation. If $[B\mid Z]=P[A\mid Y]$ with $P$ invertible, then $B=PA$ and $Z=PY$. If $AX=Y$, then $BX=P(AX)=PY=Z$. If $BX=Z$, then $AX=P^{-1}(BX)=P^{-1}Z=Y$.

The theorem is about augmented matrices. Applying operations to $A$ alone and keeping $Y$ fixed is not safe. For the two-line example, the interchange $R_1\leftrightarrow R_2$ applied to the coefficients only gives $x_1-2x_2=4$ and $2x_1+x_2=-3$, whose solution is $(-2/5,-11/5)$, not $(1,2)$. For homogeneous systems the distinction disappears, because the zero column stays zero.

10. Row-reduced matrices 22:24

Theorem 9.2 lets us replace a system by any row-equivalent one. We now name a target form in which the solutions can be read off directly. A row of a matrix is a zero row if all its entries are $0$; otherwise it is a nonzero row. The leading entry of a nonzero row is its first nonzero entry from the left.

Definition 10.1 (row-reduced matrix). A matrix $R\in F^{m\times n}$ is row-reduced if

(a) the leading entry of each nonzero row of $R$ equals $1$, and

(b) each column of $R$ that contains the leading entry of some row has all its other entries equal to $0$.

The zero matrix is row-reduced: it has no nonzero rows, so (a) and (b) impose no condition. The identity matrix is row-reduced: the leading entry of row $i$ is the $1$ in column $i$, and column $i$ has zeros elsewhere. The two matrices

$$ \begin{pmatrix}1&2\\0&3\end{pmatrix},\qquad \begin{pmatrix}1&2\\0&1\end{pmatrix} $$

are not row-reduced. In the first, the leading entry of row 2 is $3\neq1$, so (a) fails. In the second, column 2 contains the leading entry of row 2 and also the entry $2$ in row 1, so (b) fails.

The definition says nothing about the order of the rows. The matrix

$$ R=\begin{pmatrix}0&0&1&1\\1&2&0&3\\0&0&0&0\end{pmatrix} $$

is row-reduced. The leading entry of row 1 is in column 3 and that of row 2 is in column 1; columns 3 and 1 are zero apart from those leading $1$s; and row 3 is a zero row. Yet the leading $1$ of row 1 lies to the right of the leading $1$ of row 2, and the definition would allow the zero row in any position. Section 11 shows that $R$ is row-equivalent to the coefficient matrix of (R). Exercise 3 shows that the same $A$ is row-equivalent to six different row-reduced matrices, so a row-reduced form is not unique. Chapter 2 adds an ordering requirement, the echelon condition, that removes this freedom.

The solutions of $RX=0$ are visible. Row 1 says $x_3+x_4=0$, row 2 says $x_1+2x_2+3x_4=0$, and row 3 says $0=0$. Each nonzero row contains its leading unknown and no other leading unknown, by condition (b). So the unknowns $x_2$ and $x_4$, whose columns hold no leading entry, can be chosen freely, and the leading unknowns are then determined:

$$ x_1=-2x_2-3x_4,\qquad x_3=-x_4. $$

Every choice of $x_2,x_4\in F$ gives a solution, and every solution arises this way, because a solution's $x_1$ and $x_3$ are fixed by its $x_2$ and $x_4$. In vector form the solution set is $\{x_2(-2,1,0,0)+x_4(-3,0,-1,1): x_2,x_4\in F\}$. Condition (b) is what makes this reading possible: it guarantees that each leading unknown appears in exactly one equation.

11. Every matrix is row-equivalent to a row-reduced matrix 29:01

Theorem 11.1. Let $F$ be a field. Every matrix $A\in F^{m\times n}$ is row-equivalent to a row-reduced matrix $R\in F^{m\times n}$. The procedure below finds one using at most $m$ operations of type 1, at most $m(m-1)$ operations of type 2, and no interchanges.

Procedure. For $t=1,2,\dots,m$ in turn, look at the current row $t$. If it is a zero row, go to the next $t$. Otherwise let $k$ be the column of its leading entry $a$. If $a\neq1$, apply $R_t\leftarrow a^{-1}R_t$. Then, for every row $i\neq t$, above or below row $t$, whose entry in column $k$ is a nonzero $b$, apply $R_i\leftarrow R_i-bR_t$.

Proof. The procedure applies only elementary operations, so its output is row-equivalent to $A$. It is finite: each $t$ uses at most one scaling and at most $m-1$ replacements, which gives the operation counts. It remains to show that the output is row-reduced. For $t=0,1,\dots,m$, let $(\mathrm{I}_t)$ be the following statement about the matrix after rows $1,\dots,t$ have been processed: each nonzero row $j\le t$ has leading entry $1$ in a column $k_j$, and column $k_j$ is zero apart from that entry. Statement $(\mathrm{I}_0)$ is empty, hence true, and $(\mathrm{I}_m)$ says that the output is row-reduced. We show that $(\mathrm{I}_t)$ implies $(\mathrm{I}_{t+1})$.

Assume $(\mathrm{I}_t)$, and consider row $t+1$ as it stands. If it is a zero row, nothing changes, and $(\mathrm{I}_{t+1})$ holds. Otherwise let $k$ be the column of its leading entry. Every column $k_j$ with $j\le t$ is zero outside row $j$, so row $t+1$ has entry $0$ in every such column. Hence $k$ differs from every $k_j$. Scaling row $t+1$ by $a^{-1}$ changes no other row and makes the leading entry $1$; zero entries stay zero by Lemma 1.2(a). Now consider a replacement $R_i\leftarrow R_i-bR_{t+1}$ with $i\neq t+1$. Three facts show that it cannot damage rows $1,\dots,t$.

  1. Row $t+1$ is zero in every column $k_j$ with $j\le t$. So the replacement does not change any entry in those columns, and each column $k_j$ remains zero outside row $j$.
  2. Let $j\le t$ be a nonzero row with leading column $k_j$. If $k\lt k_j$, then the entry of row $j$ in column $k$ is $0$, because $k_j$ is the first nonzero position of row $j$. So $b=0$ and no operation is applied to row $j$. If $k\gt k_j$, then row $t+1$ is zero in columns $1,\dots,k-1$, so the replacement changes row $j$ only in columns $k$ and beyond, all to the right of $k_j$. In both cases row $j$ keeps its leading entry $1$ in column $k_j$.
  3. A zero row $j\le t$ has entry $0$ in column $k$, so it is not changed and stays zero.

After all replacements for this $t$, column $k$ is zero except for the leading $1$ in row $t+1$. With $k_{t+1}=k$, this gives $(\mathrm{I}_{t+1})$. By induction $(\mathrm{I}_m)$ holds. $\square$

The hinge of the proof is fact 1. Row $t+1$ already has zeros in all earlier leading columns, so subtracting its multiples never disturbs work done before. This is also why the procedure must clear column $k$ in the rows above row $t+1$, not only in the rows below. If the rows above are skipped, an earlier row can keep a nonzero entry in a later leading column, and condition (b) fails. Exercise 2 gives a matrix for which this happens.

At $t=2$ the procedure also inspects row 1 above; its entry in column 1 is already $0$, so no operation is needed. The output is the matrix $R$ of Section 10. Multiplying the five elementary matrices in order gives

$$ P=E_5E_4E_3E_2E_1=\begin{pmatrix}1/2&0&0\\-1/4&1/2&0\\-1&-1&1\end{pmatrix},\qquad PA=R. $$

One can check a row by Lemma 6.2(a): row 3 of $PA$ is $-1\cdot(0,0,2,2)-1\cdot(2,4,1,7)+1\cdot(2,4,3,9)=(0,0,0,0)$.

What the reduction answers. By Theorem 9.2, $AX=0$ and $RX=0$ have the same solutions, so Section 10 gives all solutions of the homogeneous form of (R): $X=x_2(-2,1,0,0)+x_4(-3,0,-1,1)$. For a general right-hand side, apply the same operations to $[A\mid Y]$. The coefficient part becomes $R$ and the last column becomes $PY=(y_1/2,\ y_2/2-y_1/4,\ y_3-y_1-y_2)$. The third equation of the reduced system reads $0=y_3-y_1-y_2$. So (R) is consistent if and only if $y_3=y_1+y_2$, which is the condition that Section 4 found by inspecting columns. Now it comes from a procedure that works for every matrix.

For $Y=(2,9,11)$ we get $PY=(1,4,0)$. The reduced equations are $x_3+x_4=1$ and $x_1+2x_2+3x_4=4$. Taking $x_2=x_4=0$ gives the particular solution $X_p=(4,0,1,0)$; check: $2\cdot1=2$, $2\cdot4+1=9$, $2\cdot4+3=11$. By Theorem 2.1, the complete solution set is $X_p+x_2(-2,1,0,0)+x_4(-3,0,-1,1)$ with $x_2,x_4\in\mathbb{Q}$. For $Y=(2,9,12)$ the third entry of $PY$ is $12-2-9=1$, and the reduced system contains the equation $0=1$, so no solution exists. These are the two answers that the opening asked for.

Column relations survive. The reduction also explains the relations of Section 4. A relation $\sum_jc_ja^{(j)}=0$ among the columns of $A$ says that $(c_1,\dots,c_n)$ solves $AX=0$. By Theorem 9.2 it solves $RX=0$, so the columns of $R$ satisfy the same relation, and conversely. In $R$ the relations are visible: column 2 is twice column 1, and column 4 is three times column 1 plus column 3. Row operations change the columns but keep every linear relation among them.

Boundaries of the theorem. The theorem asserts existence of a row-reduced matrix, not uniqueness; Exercise 3 exhibits six. It holds over every field, because the procedure uses only subtraction, multiplication and division by nonzero leading entries. It does not hold over $\mathbb{Z}$: the $1\times1$ matrix $(2)$ cannot be scaled to $(1)$ with integer operations, because $2$ has no integer inverse.

At $t=2$ the leading entry of row 2 is $1$ in column 3; clearing column 3 needs $R_1\leftarrow R_1-R_2$, giving $(1,2,0,-1)$, and $R_3\leftarrow R_3-R_2$, giving $(0,1,0,1)$. At $t=3$ the leading entry of row 3 is $1$ in column 2; clearing column 2 needs only $R_1\leftarrow R_1-2R_3$, giving $(1,0,0,-3)$, because row 2 has $0$ in column 2. The output is $R$ with rows $(1,0,0,-3)$, $(0,0,1,1)$, $(0,1,0,1)$. It is row-reduced but its rows are not in echelon order. Multiplying the four elementary matrices in order gives $P$ with rows $(-1,1,-2)$, $(-2,1,0)$, $(2,-1,1)$; check row 1: $-1\cdot(1,2,1,0)+1\cdot(2,4,3,1)-2\cdot(0,1,1,2)=(1,0,0,-3)$. The equations of $RX=0$ are $x_1-3x_4=0$, $x_3+x_4=0$, $x_2+x_4=0$, so $x_4$ is free and the solutions are $t(3,-1,-1,1)$ for $t\in\mathbb{Q}$; substituting into $M$ gives $3-2-1=0$, $6-4-3+1=0$ and $-1-1+2=0$. For a general $Y$, the reduced system is $RX=PY$, and $R$ has no zero row, so no equation of the form $0=c$ appears; the choice $x_4=0$, $x_1=(PY)_1$, $x_3=(PY)_2$, $x_2=(PY)_3$ is a solution. So $MX=Y$ is consistent for every $Y$. The faulty variant performs $R_2\leftarrow R_2-2R_1$, then at $t=2$ clears column 3 only in row 3, giving $(0,1,0,1)$, and at $t=3$ has no rows below. Its output has rows $(1,2,1,0)$, $(0,0,1,1)$, $(0,1,0,1)$. Column 3 contains the leading entry of row 2 and also the entry $1$ in row 1, and column 2 contains the leading entry of row 3 and also the entry $2$ in row 1, so condition (b) fails twice.

  3. Section 11 shows that $A$ is row-equivalent to $R$, whose rows are $\rho_1=(0,0,1,1)$, $\rho_2=(1,2,0,3)$ and $\rho_3=(0,0,0,0)$. Let $R'$ be any matrix whose rows are $\rho_1,\rho_2,\rho_3$ in some order. Every order is reached from $R$ by at most two interchanges, so $R'$ is row-equivalent to $R$, hence to $A$ by transitivity. $R'$ is row-reduced: condition (a) concerns each row by itself, and condition (b) concerns the entries of a column across the set of rows, and neither depends on the order of the rows. The three rows are distinct, so the $3!=6$ orders give six distinct matrices. This does not contradict Theorem 9.2, which says that row-equivalent matrices give the same solution set; it does not say that the row-reduced form is unique, and indeed all six matrices have the solution set $x_2(-2,1,0,0)+x_4(-3,0,-1,1)$ for $RX=0$. To single out one matrix, one can require in addition that the zero rows come last and that the leading columns increase from row to row. Among the six, only the matrix with rows $\rho_2,\rho_1,\rho_3$ satisfies this. This is the echelon condition of Chapter 2.

  4. Replace the second equation by itself minus the first: $-2x_2=-1$. Over $\mathbb{Q}$, divide by $-2$ to get $x_2=1/2$, and then $x_1=1-x_2=1/2$; check: $1/2+1/2=1$ and $1/2-1/2=0$. Over $\mathbb{F}_3$, $-2=1$ and $-1=2$, so the derived equation is $x_2=2$, and $x_1=1-2=-1=2$; check: $2+2=4=1$ and $2-2=0$ in $\mathbb{F}_3$. Over $\mathbb{F}_2$, $-2=0$ and $-1=1$, so the derived equation reads $0=1$ and the system is inconsistent. The step whose validity depends on the field is the division by $-2$, that is, the type-1 operation with constant $(-2)^{-1}$. It is an elementary operation only if $-2\neq0$, equivalently $1+1\neq0$ in $F$. Fields with $1+1=0$ are said to have characteristic $2$. In such a field the two equations have the same left side, $x_1+x_2$, so they are consistent only if their right sides agree, which here they do not.

  5. An elementary column operation on $A$ is the transpose of an elementary row operation on $A^{\mathsf T}$, where $A^{\mathsf T}$ is the transpose of $A$, with entries $(A^{\mathsf T})_{ij}=A_{ji}$. By Theorem 8.2 the row operation gives $EA^{\mathsf T}$, and its transpose is $(EA^{\mathsf T})^{\mathsf T}=AE^{\mathsf T}$, using the identity $(BC)^{\mathsf T}=C^{\mathsf T}B^{\mathsf T}$, which follows from Definition 6.1 by comparing entries. So the column operation is $A\mapsto AQ$ with $Q=E^{\mathsf T}$, which is invertible with inverse $(E^{-1})^{\mathsf T}$ because $E^{\mathsf T}(E^{-1})^{\mathsf T}=(E^{-1}E)^{\mathsf T}=I$. Now $(AQ)X'=Y$ holds exactly when $A(QX')=Y$, so $X'$ solves the new system if and only if $X=QX'$ solves the old one. The solution sets correspond through the bijection $X'\mapsto QX'$, but they are not equal in general. For the two-line example, exchanging the columns gives $x_1'+2x_2'=4$, $-2x_1'+x_2'=-3$, whose solution is $X'=(2,1)$; with $Q$ the $2\times2$ interchange matrix, $QX'=(1,2)$ recovers the original solution. A column interchange renames the unknowns, a column scaling by $c$ rescales one unknown by $c$, and a column replacement mixes unknowns. The set of right-hand sides $Y$ for which a solution exists does not change, because $\{AQX':X'\in F^n\}=\{AX:X\in F^n\}$ when $Q$ is invertible. A safe rule is therefore: column operations may be used to decide consistency, but each one must be recorded in a matrix $Q$, and every solution $X'$ found at the end must be converted back to $X=QX'$.

  6. Let $K$ be a subfield of $\mathbb{C}$. Then $1\in K$ and $K$ is closed under addition, so $n=1+\cdots+1\in K$ for every positive integer $n$, by induction on $n$. Since $0\in K$ and $K$ contains negatives, every integer lies in $K$. If $p,q$ are integers with $q\neq0$, then $q^{-1}\in K$ because $K$ contains inverses of its nonzero elements, and $p/q=pq^{-1}\in K$ by closure under multiplication. Hence $\mathbb{Q}\subseteq K$. The integers here are computed with the operations of $\mathbb{C}$, and the elements $n\cdot1$ are distinct for distinct $n$, which is why $K$ must be infinite. For the second part, the two tables of Section 1 define a field on $\{0,1\}$: they are addition and multiplication of integers modulo 2, the axioms follow from those of integer arithmetic, $-1=1$, and $1^{-1}=1$. A subfield of $\mathbb{R}$, however, must use the addition of $\mathbb{R}$, and in $\mathbb{R}$ the sum $1+1=2$ does not lie in $\{0,1\}$. So $\{0,1\}$ is not closed under the operations of $\mathbb{R}$ and is not a subfield. The first part gives a second reason: every subfield of $\mathbb{R}$ is a subfield of $\mathbb{C}$ and therefore contains $\mathbb{Q}$, which $\{0,1\}$ does not.

"""Chapter 1 laboratory: linear systems and elementary row operations.

Exact arithmetic over Q (fractions.Fraction) and over the prime fields
F_p (class GF).  A matrix is a list of rows; every routine returns a new
matrix and never changes its input.  An elementary row operation is a
tuple:
    ('scale', r, c)      row r becomes c * row r, with c != 0
    ('add', r, s, c)     row r becomes row r + c * row s, with r != s
    ('swap', r, s)       rows r and s are exchanged
Rows are numbered from 0 in code and from 1 in the chapter.
"""
from fractions import Fraction
from itertools import product


class GF:
    """An element of the prime field F_p = {0, 1, ..., p-1}."""

    def __init__(self, value, p):
        self.p = p
        self.v = value % p

    def _lift(self, other):
        return other if isinstance(other, GF) else GF(other, self.p)

    def __add__(self, other):
        return GF(self.v + self._lift(other).v, self.p)

    def __sub__(self, other):
        return GF(self.v - self._lift(other).v, self.p)

    def __mul__(self, other):
        return GF(self.v * self._lift(other).v, self.p)

    def __truediv__(self, other):
        other = self._lift(other)
        if other.v == 0:
            raise ZeroDivisionError('division by zero in F_p')
        return GF(self.v * pow(other.v, self.p - 2, self.p), self.p)

    def __neg__(self):
        return GF(-self.v, self.p)

    def __eq__(self, other):
        return self.v == self._lift(other).v

    def __hash__(self):
        return hash((self.v, self.p))

    def __repr__(self):
        return str(self.v)


def Q(rows):
    """Matrix over Q from integer or Fraction entries."""
    return [[Fraction(x) for x in row] for row in rows]


def Fp(rows, p):
    """Matrix over F_p from integer entries."""
    return [[GF(x, p) for x in row] for row in rows]


def identity(m, one=Fraction(1)):
    zero = one - one
    return [[one if i == j else zero for j in range(m)] for i in range(m)]


def matmul(A, B):
    return [[sum((A[i][k] * B[k][j] for k in range(1, len(B))),
                 A[i][0] * B[0][j])
             for j in range(len(B[0]))] for i in range(len(A))]


def apply_op(op, A):
    """Return e(A) for the elementary row operation op."""
    B = [row[:] for row in A]
    if op[0] == 'scale':
        _, r, c = op
        assert c != 0, 'scaling by zero is not an elementary operation'
        B[r] = [c * x for x in A[r]]
    elif op[0] == 'add':
        _, r, s, c = op
        assert r != s, 'type-2 operation needs two different rows'
        B[r] = [x + c * y for x, y in zip(A[r], A[s])]
    else:
        _, r, s = op
        B[r], B[s] = A[s][:], A[r][:]
    return B


def inverse_op(op):
    """The elementary operation of the same type that undoes op."""
    if op[0] == 'scale':
        return ('scale', op[1], 1 / op[2])
    if op[0] == 'add':
        return ('add', op[1], op[2], -op[3])
    return op


def elementary_matrix(op, m, one=Fraction(1)):
    """E = e(I) for the m x m identity."""
    return apply_op(op, identity(m, one))


def row_reduce(A):
    """Reduce A to a row-reduced matrix without interchanging rows.

    Rows are processed from top to bottom.  A nonzero row is scaled so
    that its first nonzero entry becomes 1; that entry's column is then
    cleared in EVERY other row, above and below.  Returns (R, ops) with
    R = e_k(...e_1(A)) for ops = [e_1, ..., e_k].
    """
    R = [row[:] for row in A]
    ops = []
    for t in range(len(R)):
        lead = next((k for k, x in enumerate(R[t]) if x != 0), None)
        if lead is None:
            continue
        if R[t][lead] != 1:
            op = ('scale', t, 1 / R[t][lead])
            R = apply_op(op, R)
            ops.append(op)
        for i in range(len(R)):
            if i != t and R[i][lead] != 0:
                op = ('add', i, t, -R[i][lead])
                R = apply_op(op, R)
                ops.append(op)
    return R, ops


def is_row_reduced(A):
    """Condition (a): leading entry of each nonzero row is 1.
    Condition (b): a column holding a leading entry is otherwise zero."""
    for t, row in enumerate(A):
        lead = next((k for k, x in enumerate(row) if x != 0), None)
        if lead is None:
            continue
        if row[lead] != 1:
            return False
        if any(A[i][lead] != 0 for i in range(len(A)) if i != t):
            return False
    return True


def is_solution(A, X, Y):
    return all(sum((a * x for a, x in zip(row, X)), y - y) == y
               for row, y in zip(A, Y))


def augment(A, Y):
    return [row + [y] for row, y in zip(A, Y)]


def fmt_op(op):
    """Write an operation in the chapter's 1-based notation."""
    if op[0] == 'scale':
        return f'R{op[1] + 1} <- ({op[2]}) R{op[1] + 1}'
    if op[0] == 'add':
        return f'R{op[1] + 1} <- R{op[1] + 1} + ({op[3]}) R{op[2] + 1}'
    return f'R{op[1] + 1} <-> R{op[2] + 1}'


def show(M):
    return '[' + '; '.join(' '.join(str(x) for x in row)
                           for row in M) + ']'

              ('add', 2, 0, Fraction(-1)), ('swap', 0, 2)]

    assert apply_op(op, A) == matmul(elementary_matrix(op, 3), A)
    assert apply_op(inverse_op(op), apply_op(op, A)) == A

    assert matmul(E, F) == I3 and matmul(F, E) == I3

      len(sample_ops), 'operations')

assert consistent[2] == Q([[0, 0, 0, 0, 0]])[0]

def reduce_below_only(A):
    """The faulty variant: clear each leading column only below."""
    B = [row[:] for row in A]
    for t in range(len(B)):
        lead = next((k for k, x in enumerate(B[t]) if x != 0), None)
        if lead is None:
            continue
        B = apply_op(('scale', t, 1 / B[t][lead]), B)
        for i in range(t + 1, len(B)):
            B = apply_op(('add', i, t, -B[i][lead]), B)
    return B
