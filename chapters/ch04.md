# Linear independence, basis, and the invariance of dimension

In $\mathbb{Q}^4$ consider the four vectors

$$
v_1=(1,1,0,0),\quad v_2=(0,1,1,0),\quad v_3=(0,0,1,1),\quad v_4=(1,3,1,-1).
$$

They form the running example of this chapter (an original construction), written here as rows to save space and treated as column vectors. A *linear combination* of vectors is a sum $c_1v_1+\cdots+c_kv_k$ with scalars $c_i$, and the *span* of a set is the set of all its linear combinations; the span is the smallest subspace that contains the set ([Chapter 3](ch03.md)). Let $U$ be the span of $v_1,\dots,v_4$.

How large is $U$? Four vectors describe it, but they waste information: a direct check shows

$$
v_4=v_1+2v_2-v_3 .
$$

So $v_4$ contributes nothing, and $U$ is already the span of $v_1,v_2,v_3$. Could some cleverer choice describe $U$ by two vectors? The picture of a line or a plane suggests that the number of vectors needed is a property of $U$ itself, not of the vectors we happen to choose. This chapter proves that. The number is called the *dimension* of $U$, and here it is $3$. Making this precise needs two properties of a list of vectors: it must reach everything (span) and it must contain no redundancy (independence).

Throughout, $F$ is a field and $V$ is a vector space over $F$. We write $\mathbf{0}$ for the zero vector.

## 1. Spans of arbitrary sets [00:25](https://www.youtube.com/watch?v=mNB7cDaXshQ&t=25s)

For a subset $S\subseteq V$, finite or infinite, $\operatorname{span}(S)$ is the set of all finite sums $c_1\alpha_1+\cdots+c_k\alpha_k$ with $\alpha_i\in S$ and $c_i\in F$; the empty sum is $\mathbf{0}$. Each combination uses finitely many vectors, because the axioms define only finite sums. The span is a subspace: if $\alpha=\sum_ic_i\alpha_i$ and $\beta=\sum_jt_j\beta_j$ are two such sums and $c\in F$, then $c\alpha+\beta=\sum_icc_i\alpha_i+\sum_jt_j\beta_j$ is again a finite combination of elements of $S$. A set $S$ *spans* $V$ if $\operatorname{span}(S)=V$.

## 2. Linear dependence and independence [07:10](https://www.youtube.com/watch?v=mNB7cDaXshQ&t=430s)

**Definition 2.1.** A subset $S\subseteq V$ is *linearly dependent* if there are distinct vectors $\alpha_1,\dots,\alpha_n\in S$ and scalars $c_1,\dots,c_n$, not all zero, with $c_1\alpha_1+\cdots+c_n\alpha_n=\mathbf{0}$. Otherwise $S$ is *linearly independent*. A list $(\alpha_1,\dots,\alpha_n)$ is called independent if $\sum c_i\alpha_i=\mathbf{0}$ forces all $c_i=0$.

The difference between a set and a list matters in one case only: a list can repeat a vector, and a list with a repeated vector $\alpha_i=\alpha_j$ is dependent, since $\alpha_i-\alpha_j=\mathbf{0}$. An equation $\sum c_i\alpha_i=\mathbf{0}$ with some $c_i\neq0$ is a *nontrivial relation*. Independence says that the only relation is the trivial one.

For the running example, $v_1+2v_2-v_3-v_4=\mathbf{0}$ is a nontrivial relation, so $\{v_1,v_2,v_3,v_4\}$ is dependent. The list $(v_1,v_2,v_3)$ is independent: $c_1v_1+c_2v_2+c_3v_3=(c_1,\,c_1+c_2,\,c_2+c_3,\,c_3)$, and this vanishes only if $c_1=0$, then $c_2=0$, then $c_3=0$.

Immediate consequences of the definition:

- A set containing $\mathbf{0}$ is dependent, because $1\cdot\mathbf{0}=\mathbf{0}$.
- A subset of an independent set is independent, and a set containing a dependent set is dependent.
- The empty set is independent, since there is no relation to check.
- A single vector $\alpha$ is independent exactly when $\alpha\neq\mathbf{0}$: if $c\alpha=\mathbf{0}$ with $c\neq0$, multiplying by $c^{-1}$ gives $\alpha=\mathbf{0}$.

**Proposition 2.2.** A set $S$ is linearly dependent if and only if some $\alpha\in S$ lies in $\operatorname{span}(S\setminus\{\alpha\})$. In that case $\operatorname{span}(S\setminus\{\alpha\})=\operatorname{span}(S)$.

**Proof.** If $\sum c_i\alpha_i=\mathbf{0}$ with, say, $c_1\neq0$, then $\alpha_1=\sum_{i\ge2}(-c_i/c_1)\alpha_i$. Conversely, if $\alpha=\sum d_j\beta_j$ with $\beta_j\in S\setminus\{\alpha\}$ distinct, then $\alpha-\sum d_j\beta_j=\mathbf{0}$ is a relation in which $\alpha$ has coefficient $1$. For the last claim, any combination that uses $\alpha$ can replace $\alpha$ by $\sum d_j\beta_j$, which uses only elements of $S\setminus\{\alpha\}$. $\square$

The proposition is the precise meaning of "redundancy". The division by $c_1$ is where we use that $F$ is a field. Over the integers the relation $2\cdot 3+(-3)\cdot2=0$ holds between $3$ and $2$, yet neither is an integer multiple of the other.

The standard examples in $F^n$ are the *unit vectors* $e_i$, with $1$ in position $i$ and $0$ elsewhere. Since $x_1e_1+\cdots+x_ne_n=(x_1,\dots,x_n)$, a combination vanishes only if all $x_i=0$; so $e_1,\dots,e_n$ are independent. In $\mathbb{R}^3$ the vectors $(1,1,0)$, $(1,0,0)$ and $(2,1,0)$ are dependent, because the first two add to the third.

## 3. Basis [15:17](https://www.youtube.com/watch?v=mNB7cDaXshQ&t=917s)

**Definition 3.1.** A *basis* of $V$ is a linearly independent subset of $V$ that spans $V$.

A basis reaches every vector, and in exactly one way, as Section 8 shows.

**Example 3.2.** The unit vectors form the *standard basis* of $F^n$: they are independent by Section 2, and $(x_1,\dots,x_n)=\sum x_ie_i$ shows that they span.

**Example 3.3.** Let $P_n(F)$ be the space of polynomials $a_0+a_1x+\cdots+a_nx^n$ with coefficients in $F$, where two polynomials are equal exactly when all their coefficients agree. The monomials $1,x,\dots,x^n$ span it by definition, and a combination $\sum a_ix^i$ is the zero polynomial exactly when every $a_i=0$. So they form a basis of $n+1$ elements.

The words "polynomial" and "polynomial function" must be kept apart here. Over $\mathbb{R}$ a nonzero polynomial of degree at most $n$ has at most $n$ roots, so it cannot vanish everywhere, and the monomial *functions* are also independent. Over the field $\mathbb{F}_2=\{0,1\}$ of integers modulo $2$, the polynomial $x+x^2$ is not zero, but the function $t\mapsto t+t^2$ vanishes at both $0$ and $1$. As functions, $x$ and $x^2$ are equal, so the monomial functions are dependent. The argument "a polynomial of degree $n$ has only $n$ roots" needs a field with more than $n$ elements; the coefficient definition needs nothing.

**Example 3.4.** Let $P\in F^{n\times n}$ have columns $p_1,\dots,p_n$. Then $x_1p_1+\cdots+x_np_n=PX$ with $X=(x_1,\dots,x_n)$. If $P$ is invertible, $PX=0$ forces $X=P^{-1}0=0$, so the columns are independent, and for every $Y\in F^n$ the vector $X=P^{-1}Y$ gives $Y=\sum x_ip_i$, so they span. Conversely, suppose the columns form a basis. Spanning gives vectors $b_j$ with $Pb_j=e_j$, so $PB=I$ for the matrix $B$ with columns $b_j$. Then $P(BP-I)=(PB)P-P=0$. Each column of $BP-I$ is a solution of $PX=0$, which by independence is zero. So $BP=I$, and $P$ is invertible. Thus *the columns of a square matrix form a basis of $F^n$ exactly when the matrix is invertible*.

## 4. Dimension: finite and infinite [26:14](https://www.youtube.com/watch?v=mNB7cDaXshQ&t=1574s)

We call $V$ *finite-dimensional* if it has a finite basis, and *infinite-dimensional* otherwise. We would like to call the number of elements of a basis the *dimension* of $V$. This is legitimate only if all bases have the same number of elements, which is the content of the next section. First we give an example of an infinite-dimensional space.

Let $F[x]$ be the space of all polynomials over $F$. Suppose finitely many polynomials $f_1,\dots,f_k$ spanned $F[x]$, and let $N$ be the largest of their degrees (if all are zero, take $N=0$). Every combination of the $f_i$ has no term of degree above $N$, so $x^{N+1}$ is not a combination. Hence no finite set spans $F[x]$, and in particular $F[x]$ has no finite basis. It does have an infinite basis, $\{1,x,x^2,\dots\}$: each polynomial is a finite combination of monomials, and a finite combination of monomials vanishes only when its coefficients do.

## 5. The key inequality [33:20](https://www.youtube.com/watch?v=mNB7cDaXshQ&t=2000s)

**Theorem 5.1.** Suppose $V$ is spanned by $\beta_1,\dots,\beta_m$. Then every linearly independent set in $V$ has at most $m$ elements. Equivalently, any $n\gt m$ vectors of $V$ are dependent.

**Proof.** Take vectors $\alpha_1,\dots,\alpha_n$ with $n\gt m$. Since the $\beta_i$ span $V$, there are scalars $P_{ij}$ with

$$
\alpha_j=\sum_{i=1}^mP_{ij}\beta_i\qquad(1\le j\le n).
$$

The scalars form a matrix $P\in F^{m\times n}$ with more columns than rows. By [Chapter 2](ch02.md), a homogeneous system with fewer equations than unknowns has a nonzero solution. So there is $X\neq0$ with $PX=0$. Then

$$
\sum_{j=1}^nx_j\alpha_j=\sum_{j=1}^nx_j\sum_{i=1}^mP_{ij}\beta_i=\sum_{i=1}^m\Big(\sum_{j=1}^nP_{ij}x_j\Big)\beta_i=\sum_{i=1}^m0\cdot\beta_i=\mathbf{0}.
$$

This is a nontrivial relation among the $\alpha_j$, so they are dependent. $\square$

The hinge is the exchange of the two finite sums: it turns a question about vectors in an arbitrary space $V$ into a homogeneous system over $F$, where row reduction settles it. Nothing about $V$ enters except that finitely many vectors span it.

**Corollary 5.2 (invariance of dimension).** If $V$ has a finite basis, then every basis of $V$ is finite and all bases have the same number of elements.

**Proof.** Let $B$ be a basis with $m$ elements and $B'$ another basis. $B'$ is independent and $B$ spans, so $B'$ has at most $m$ elements. Then $B'$ is finite, and it spans, while $B$ is independent, so $B$ has at most as many elements as $B'$. $\square$

**Definition 5.3.** For finite-dimensional $V$, the *dimension* $\dim V$ is the number of elements of any basis. The zero space has the empty basis and dimension $0$.

Thus $\dim F^n=n$ and $\dim P_n(F)=n+1$. This settles the question of the opening: by Theorem 5.1, no two vectors can span a space that contains three independent vectors, so no clever choice describes $U$ by two vectors.

The dimension depends on the field of scalars. The space $\mathbb{C}$ over $\mathbb{C}$ has basis $\{1\}$ and dimension $1$. Over $\mathbb{R}$ every complex number is $a\cdot1+b\cdot i$ with unique real $a,b$, so $\{1,i\}$ is a basis and the dimension is $2$. Over $\mathbb{Q}$ the space $\mathbb{R}$ is infinite-dimensional: a basis of $n$ elements would put $\mathbb{R}$ in one-to-one correspondence with $\mathbb{Q}^n$, which is countable (its elements can be listed in a sequence), while $\mathbb{R}$ is not.

## 6. Building bases: extension and reduction [00:25](https://www.youtube.com/watch?v=wXhtEtJQx2U&t=25s)

**Lemma 6.1.** Let $S\subseteq V$ be linearly independent and let $\beta\notin\operatorname{span}(S)$. Then $S\cup\{\beta\}$ is linearly independent.

**Proof.** Take a relation $a_0\beta+a_1\alpha_1+\cdots+a_n\alpha_n=\mathbf{0}$ with distinct $\alpha_i\in S$. If $a_0\neq0$, then $\beta=\sum_{i\ge1}(-a_i/a_0)\alpha_i$ lies in $\operatorname{span}(S)$, contrary to the hypothesis. So $a_0=0$, and then $\sum a_i\alpha_i=\mathbf{0}$ forces all $a_i=0$ by independence of $S$. $\square$

**Theorem 6.2.** Let $V$ be spanned by $m$ vectors.

1. (Extension) Every independent set $S\subseteq V$ can be enlarged to a basis of $V$.
2. (Reduction) Every finite spanning set contains a basis.

Consequently $V$ is finite-dimensional with $\dim V\le m$.

**Proof.** (1) $S$ has at most $m$ elements by Theorem 5.1. If $S$ does not span $V$, pick $\beta\notin\operatorname{span}(S)$; by Lemma 6.1, $S\cup\{\beta\}$ is independent. Repeat. Each step adds one element, and independent sets have at most $m$ elements, so the process stops. It stops only when the set spans $V$, and then it is a basis. (2) If a finite spanning set $T$ is dependent, Proposition 2.2 gives an element whose removal does not change the span. Remove it and repeat. The set shrinks at each step, so the process stops at an independent spanning set. For the last statement, part (2) applied to the given $m$ vectors gives a basis with at most $m$ elements. $\square$

Applying part (1) to $(v_1,v_2,v_3)$ in $\mathbb{Q}^4$, the vector $e_1$ is not in $U$: every $v_i$ satisfies $x_1-x_2+x_3-x_4=0$, so every vector of $U$ does, while $e_1$ gives $1$. So $(v_1,v_2,v_3,e_1)$ is a basis of $\mathbb{Q}^4$.

**Corollary 6.3.** Let $\dim V=n$. (a) Any $n$ independent vectors form a basis. (b) Any $n$ vectors that span $V$ form a basis. (c) Every subspace $W$ of $V$ is finite-dimensional with $\dim W\le n$, and $\dim W=n$ only if $W=V$.

**Proof.** (a) Extend them to a basis; a basis has $n$ elements, so nothing is added. (b) Reduce them to a basis; it must keep all $n$. (c) An independent subset of $W$ is independent in $V$, so it has at most $n$ elements. Starting from the empty set and applying Lemma 6.1 inside $W$ therefore terminates with a basis of $W$, of size at most $n$. If its size is $n$, it is a basis of $V$ by (a), so $W=V$. $\square$

In the running example, $\dim U=3$: the vectors $v_1,v_2,v_3$ are independent and span $U$. Both hypotheses of the corollary matter in infinite dimension. In $F[x]$ the subspace $xF[x]$ of multiples of $x$ has the infinite basis $\{x,x^2,\dots\}$, which can be matched one-to-one with that of $F[x]$, and still $xF[x]\neq F[x]$.

## 7. The dimension of a sum [04:36](https://www.youtube.com/watch?v=wXhtEtJQx2U&t=276s)

For subspaces $W_1,W_2$ of $V$ the *sum* $W_1+W_2=\{w_1+w_2: w_i\in W_i\}$ and the intersection $W_1\cap W_2$ are subspaces. In $\mathbb{R}^3$ let $W_1$ be the $xy$-plane and $W_2$ the $x$-axis. Then $W_1\cap W_2=W_2$ and $W_1+W_2=W_1$, and $2+1=1+2$. The general statement is the following.

**Theorem 7.1.** Let $W_1,W_2$ be finite-dimensional subspaces of $V$. Then $W_1+W_2$ is finite-dimensional, and

$$
\dim W_1+\dim W_2=\dim(W_1\cap W_2)+\dim(W_1+W_2).
$$

**Proof.** $W_1\cap W_2$ is a subspace of $W_1$, hence finite-dimensional by Corollary 6.3(c). Let $\alpha_1,\dots,\alpha_k$ be a basis of it. By Theorem 6.2(1), extend it to a basis $\alpha_1,\dots,\alpha_k,\beta_1,\dots,\beta_m$ of $W_1$ and to a basis $\alpha_1,\dots,\alpha_k,\gamma_1,\dots,\gamma_n$ of $W_2$. We show that the list of all $\alpha_i$, $\beta_j$, $\gamma_r$ is a basis of $W_1+W_2$.

*Spanning.* Each $w\in W_1+W_2$ is $w_1+w_2$, where $w_1$ is a combination of the $\alpha_i,\beta_j$ and $w_2$ of the $\alpha_i,\gamma_r$. Adding gives a combination of all of them.

*Independence.* Suppose $\sum a_i\alpha_i+\sum b_j\beta_j+\sum g_r\gamma_r=\mathbf{0}$. Put $z=\sum g_r\gamma_r$. Then $z\in W_2$ and also $z=-\sum a_i\alpha_i-\sum b_j\beta_j\in W_1$. So $z\in W_1\cap W_2$, and there are scalars with $z=\sum p_i\alpha_i$. Hence $\sum p_i\alpha_i-\sum g_r\gamma_r=\mathbf{0}$. This is a relation in the basis of $W_2$, so all $p_i$ and all $g_r$ vanish. The original relation becomes $\sum a_i\alpha_i+\sum b_j\beta_j=\mathbf{0}$, a relation in the basis of $W_1$, so all $a_i$ and $b_j$ vanish.

The basis of $W_1+W_2$ has $k+m+n$ elements, and $(k+m)+(k+n)=k+(k+m+n)$. $\square$

The hinge is the vector $z$: a relation across two subspaces forces one part into the intersection. For the running example, let $W$ be the span of $v_1$ and $(0,1,0,1)$. These two are independent, so $\dim W=2$. The second vector violates $x_1-x_2+x_3-x_4=0$, so $W\not\subseteq U$ and $\dim(U+W)\gt3$; hence $U+W=\mathbb{Q}^4$. The formula gives $\dim(U\cap W)=3+2-4=1$, and indeed $v_1\in U\cap W$, so $U\cap W$ is the line spanned by $v_1$.

The formula resembles the counting rule for finite sets, $|A\cup B|=|A|+|B|-|A\cap B|$, but the analogy stops at two. For three distinct lines through the origin in a plane, each of dimension $1$, all pairwise intersections are zero, and the three-set version of the rule would predict $\dim=1+1+1=3$. The sum of the three lines is the plane, of dimension $2$.

## 8. Ordered bases and coordinates [21:41](https://www.youtube.com/watch?v=wXhtEtJQx2U&t=1301s)

A basis is a set, so $\{\alpha_1,\alpha_2,\alpha_3\}$ and $\{\alpha_2,\alpha_1,\alpha_3\}$ are the same basis. To record a vector by numbers we must know which number belongs to which basis vector. An *ordered basis* $\mathcal{B}=(\alpha_1,\dots,\alpha_n)$ is a list of vectors whose set is a basis, with a fixed order and no repetition.

**Theorem 8.1.** Let $\mathcal{B}=(\alpha_1,\dots,\alpha_n)$ be an ordered basis of $V$. Each $\alpha\in V$ can be written in exactly one way as $\alpha=\sum x_i\alpha_i$ with $x_i\in F$.

**Proof.** Existence is spanning. If $\sum x_i\alpha_i=\sum c_i\alpha_i$, then $\sum(x_i-c_i)\alpha_i=\mathbf{0}$, and independence gives $x_i=c_i$. $\square$

The column $(x_1,\dots,x_n)^{\mathsf T}$, where the superscript $\mathsf T$ means that the list is written as a column, is the *coordinate matrix* of $\alpha$ relative to $\mathcal{B}$, written $[\alpha]_{\mathcal{B}}$. The map $\alpha\mapsto[\alpha]_{\mathcal{B}}$ from $V$ to $F^n$ is one-to-one by uniqueness and onto because every column $X$ is the coordinate matrix of $\sum x_i\alpha_i$. It also respects the operations: if $\alpha=\sum x_i\alpha_i$ and $\beta=\sum y_i\alpha_i$, then $c\alpha+\beta=\sum(cx_i+y_i)\alpha_i$, so $[c\alpha+\beta]_{\mathcal{B}}=c[\alpha]_{\mathcal{B}}+[\beta]_{\mathcal{B}}$. In every calculation with sums and scalar multiples, an $n$-dimensional space therefore behaves like $F^n$.

**Example 8.2.** In $F^3$ take $\mathcal{B}=\big((1,1,1),(1,1,0),(1,0,0)\big)$. To find the coordinates of $(a,b,c)$ we solve $g_1(1,1,1)+g_2(1,1,0)+g_3(1,0,0)=(a,b,c)$, that is, $g_1+g_2+g_3=a$, $g_1+g_2=b$, $g_1=c$. So $[(a,b,c)]_{\mathcal{B}}=(c,\,b-c,\,a-b)^{\mathsf T}$. This holds over every field, which also shows that $\mathcal{B}$ is a basis: every vector has exactly one such expression.

In the running example with $\mathcal{B}=(v_1,v_2,v_3)$ of $U$, the relation $v_4=v_1+2v_2-v_3$ says $[v_4]_{\mathcal{B}}=(1,2,-1)^{\mathsf T}$. For another ordered basis, $\mathcal{B}'=(v_1,\ v_1+v_2,\ v_2+v_3)$, we have $v_4=-2v_1+3(v_1+v_2)-(v_2+v_3)$, so $[v_4]_{\mathcal{B}'}=(-2,3,-1)^{\mathsf T}$. One vector, two coordinate columns. They are connected by a matrix: the columns of

$$
P=\begin{pmatrix}1&1&0\\0&1&1\\0&0&1\end{pmatrix}
$$

are the $\mathcal{B}$-coordinates of the three vectors of $\mathcal{B}'$, and $P(-2,3,-1)^{\mathsf T}=(1,2,-1)^{\mathsf T}$. That such an invertible matrix exists for every pair of ordered bases is the subject of [Chapter 5](ch05.md).

For a dependent spanning list uniqueness fails. With the list $(v_1,v_2,v_3,v_4)$, the vector $v_4$ has the two expressions $1\cdot v_4$ and $v_1+2v_2-v_3$. This is the sense in which a basis is the right amount of data: spanning gives existence of coordinates, independence gives uniqueness.

## 9. Executable check

[The chapter laboratory](../labs/ch04.py) works with exact fractions. It confirms the relation $v_1+2v_2-v_3-v_4=0$ and that $(v_1,v_2,v_3)$ is independent, extends it by $(1,0,0,0)$ to a basis of $\mathbb{Q}^4$, computes $[v_4]_{\mathcal{B}}=(1,2,-1)$, $[v_4]_{\mathcal{B}'}=(-2,3,-1)$ and $P$, and finds $\dim U=3$, $\dim W=2$, $\dim(U+W)=4$, $\dim(U\cap W)=1$. It tests the dimension formula on 200 random pairs of subspaces and exhibits the failure for three lines. Over $\mathbb{F}_2^3$ it enumerates every set of nonzero vectors and finds $28$ bases, all of size $3$, and that every minimal spanning set and every maximal independent set is a basis size. The proofs above cover the general case; the laboratory only checks instances.

## Exercises

1. (Computation.) Show that $(1,\,1+x,\,(1+x)^2)$ is an ordered basis of $P_2(\mathbb{Q})$, and find the coordinate matrix of $x^2$ relative to it.
2. (Field dependence.) Decide whether $(1,1,0)$, $(0,1,1)$, $(1,0,1)$ form a basis of $\mathbb{Q}^3$, and of $\mathbb{F}_2^3$.
3. (Dimension count.) Assume $1+1\neq0$ in $F$. Find bases of the spaces of symmetric ($A^{\mathsf T}=A$) and skew-symmetric ($A^{\mathsf T}=-A$) matrices in $F^{n\times n}$, and check that the dimensions add to $n^2$.
4. (Proof.) Let $W_1,W_2$ be subspaces of dimension $n-1$ of an $n$-dimensional space, with $W_1\neq W_2$ and $n\ge2$. Find $\dim(W_1\cap W_2)$.
5. (Counting.) Let $F=\mathbb{F}_p$. Count the ordered bases of $F^n$, and deduce the number of bases (as sets) of $\mathbb{F}_2^3$.
6. (Field of scalars.) Let $V$ be a vector space over $\mathbb{C}$ with basis $(\alpha_1,\dots,\alpha_n)$. Show that the same set $V$, with scalars restricted to $\mathbb{R}$, has dimension $2n$.

<details><summary>Fully worked solutions</summary>

1. A relation $a\cdot1+b(1+x)+c(1+x)^2=0$ expands to $(a+b+c)+(b+2c)x+cx^2=0$. So $c=0$, then $b=0$, then $a=0$: the list is independent. Since $\dim P_2(\mathbb{Q})=3$, Corollary 6.3(a) makes it a basis. For the coordinates, solve $a+b+c=0$, $b+2c=0$, $c=1$: $b=-2$, $a=1$. So $[x^2]=(1,-2,1)^{\mathsf T}$, which says $x^2=1-2(1+x)+(1+x)^2$.

2. A relation $a(1,1,0)+b(0,1,1)+c(1,0,1)=0$ gives $a+c=0$, $a+b=0$, $b+c=0$. The first two give $c=-a$ and $b=-a$, so the third gives $-2a=0$. Over $\mathbb{Q}$ this forces $a=0$, hence $b=c=0$; the three independent vectors in a 3-dimensional space form a basis. Over $\mathbb{F}_2$ we have $2=0$, so $a=1$, $b=c=1$ solves it: the three vectors add to $(2,2,2)=0$. They are dependent and do not form a basis. They span a subspace of dimension $2$, since the first two are independent.

3. Let $E_{ij}$ be the matrix with $1$ in position $(i,j)$ and $0$ elsewhere. A symmetric $A$ equals $\sum_iA_{ii}E_{ii}+\sum_{i\lt j}A_{ij}(E_{ij}+E_{ji})$, so the matrices $E_{ii}$ and $E_{ij}+E_{ji}$ $(i\lt j)$ span. They are independent because each one has a nonzero entry in a position $(i,j)$ with $i\le j$ where all the others are zero. There are $n+\binom n2=n(n+1)/2$ of them. A skew-symmetric $A$ has $A_{ii}=-A_{ii}$, so $2A_{ii}=0$ and $A_{ii}=0$ since $2\neq0$. Hence $A=\sum_{i\lt j}A_{ij}(E_{ij}-E_{ji})$, and the matrices $E_{ij}-E_{ji}$ are independent by the same position argument. There are $n(n-1)/2$. The sum of the two dimensions is $n^2$.

4. Since $W_1\neq W_2$ and both have dimension $n-1$, $W_2\not\subseteq W_1$ (otherwise Corollary 6.3(c) applied to $W_2\subseteq W_1$ gives $W_2=W_1$). So $W_1+W_2$ strictly contains $W_1$, and its dimension is larger than $n-1$, again by Corollary 6.3(c). Hence $\dim(W_1+W_2)=n$. Theorem 7.1 gives $\dim(W_1\cap W_2)=(n-1)+(n-1)-n=n-2$. For $n=3$ this says that two distinct planes through the origin meet in a line.

5. An ordered basis $(\alpha_1,\dots,\alpha_n)$ is built one vector at a time. By Lemma 6.1 and Proposition 2.2, a list is independent exactly when each $\alpha_k$ lies outside the span of the earlier ones. The span of $k-1$ independent vectors has $p^{k-1}$ elements, by unique coordinates. So there are $p^n-p^{k-1}$ choices for $\alpha_k$, and the number of ordered bases is $(p^n-1)(p^n-p)\cdots(p^n-p^{n-1})$. Each independent list of length $n$ is a basis by Corollary 6.3(a). For $p=2$, $n=3$: $7\cdot6\cdot4=168$. Each basis set of three vectors corresponds to $3!=6$ ordered bases, so there are $28$ bases.

6. We show that $(\alpha_1,i\alpha_1,\dots,\alpha_n,i\alpha_n)$ is a basis over $\mathbb{R}$. Spanning: each $v\in V$ is $\sum z_k\alpha_k$ with $z_k=a_k+ib_k$, $a_k,b_k$ real, so $v=\sum a_k\alpha_k+\sum b_k(i\alpha_k)$. Independence: if $\sum a_k\alpha_k+\sum b_k(i\alpha_k)=0$ with real $a_k,b_k$, then $\sum(a_k+ib_k)\alpha_k=0$. Independence over $\mathbb{C}$ gives $a_k+ib_k=0$, and since $a_k,b_k$ are real, both vanish. So the real dimension is $2n$. The count shows why the field must be named when a dimension is stated.

</details>
