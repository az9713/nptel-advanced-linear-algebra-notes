25. Normal operators and spectral resolution

Consider the symmetric matrix

$$S=\begin{pmatrix}2&1&1\\1&2&1\\1&1&2\end{pmatrix}.$$

What is $S^{10}$? Is there a matrix $R$ with $R^2=S$? Both questions become trivial once $\mathbb{R}^3$ has an orthonormal basis of eigenvectors of $S$, because then $S$ only stretches mutually perpendicular directions: here by $4$ along $(1,1,1)$ and by $1$ on the plane perpendicular to it. This chapter determines exactly which operators behave in this way. Over $\mathbb{C}$ they are the normal operators, those that commute with their adjoint; over $\mathbb{R}$ they are the self-adjoint ones. The matrix $S$ is the running example (an original choice).

Conventions. $V$ is an inner product space over $F=\mathbb{R}$ or $\mathbb{C}$, with $\langle\cdot,\cdot\rangle$ linear in the first argument, and finite-dimensional of dimension $n\ge1$ unless stated. $T^*$ is the adjoint, $\langle T\alpha,\beta\rangle=\langle\alpha,T^*\beta\rangle$, whose matrix in an orthonormal basis is the conjugate transpose (Chapter 23). $T$ is self-adjoint if $T^*=T$, unitary if $T^*=T^{-1}$, and normal if $TT^*=T^*T$. A matrix $A$ is Hermitian if $A^*=A$, normal if $AA^*=A^*A$, unitary if $A^*A=I$.

We recall from Chapter 24: self-adjoint and unitary operators are normal; the eigenvalues of a self-adjoint operator are real, with orthogonal eigenvectors for different eigenvalues.

1. A self-adjoint operator has an eigenvector 00:25

Theorem 1.1. A self-adjoint operator on $V$ has an eigenvector.

Proof. Let $A$ be the matrix of $T$ in an orthonormal basis; then $A^*=A$. The polynomial $\det(xI-A)$ has degree $n\ge1$, so it has a root $c\in\mathbb{C}$, and there is a nonzero $X\in\mathbb{C}^n$ with $AX=cX$. The operator $X\mapsto AX$ on $\mathbb{C}^n$ is self-adjoint, so $c$ is real. If $F=\mathbb{C}$, $X$ gives an eigenvector of $T$. If $F=\mathbb{R}$, then $A-cI$ is a real matrix that is singular, so it has a nonzero kernel vector in $\mathbb{R}^n$. $\square$

Where the hypotheses enter 08:01: over $\mathbb{C}$ every operator has an eigenvector, self-adjoint or not. Over $\mathbb{R}$ self-adjointness is what makes the root real. A quarter turn of $\mathbb{R}^2$ has no eigenvector.

Infinite dimension 11:32. Let $V=C[0,1]$, the continuous complex functions, with $\langle f,g\rangle=\int_0^1f\bar g$, and $(Tf)(t)=tf(t)$. Then $\langle Tf,g\rangle=\int tf\bar g=\langle f,Tg\rangle$, so $T$ is self-adjoint. If $Tf=cf$, then $(t-c)f(t)=0$ for all $t$, so $f(t)=0$ except possibly at $t=c$, and by continuity $f=0$. So $T$ has no eigenvector.

2. Invariant subspaces and their complements 16:00

Lemma 2.1. If $W$ is a $T$-invariant subspace ($TW\subseteq W$), then $W^{\perp}$ is $T^*$-invariant.

Proof. For $\alpha\in W$ and $\beta\in W^{\perp}$, $\langle\alpha,T^*\beta\rangle=\langle T\alpha,\beta\rangle=0$ because $T\alpha\in W$. $\square$

3. Orthonormal eigenbases for self-adjoint operators 23:38

Theorem 3.1. If $T$ is self-adjoint, then $V$ has an orthonormal basis of eigenvectors of $T$.

Proof. Induct on $n$. By Theorem 1.1 there is a unit eigenvector $\alpha_1$; this settles $n=1$. For $n\gt1$ let $W=\operatorname{span}(\alpha_1)$. It is $T$-invariant, so $W^{\perp}$ is invariant under $T^*=T$ (Lemma 2.1). The restriction of $T$ to $W^{\perp}$ is self-adjoint, and $\dim W^{\perp}=n-1$. By induction $W^{\perp}$ has an orthonormal eigenbasis $\alpha_2,\dots,\alpha_n$. Since $V=W\oplus W^{\perp}$, the list $\alpha_1,\dots,\alpha_n$ is the required basis. $\square$

The hinge is Lemma 2.1: removing one eigenvector leaves a space on which $T$ still acts, with the same property.

Corollary 3.2 00:26. For a Hermitian $A\in\mathbb{C}^{n\times n}$ there is a unitary $P$ with $P^{-1}AP$ real diagonal. For a real symmetric $A$, $P$ can be chosen real orthogonal.

Proof. Apply Theorem 3.1 to $X\mapsto AX$ on $F^n$, and let the columns of $P$ be the orthonormal eigenvectors. Then $AP=PD$ and $P^*P=I$. $\square$

On the running example. $S(1,1,1)^{\mathsf T}=4(1,1,1)^{\mathsf T}$, and every vector with coordinate sum $0$ is fixed. The eigenvectors $(1,-1,0)$ and $(1,0,-1)$ for the eigenvalue $1$ are not orthogonal: inside an eigenspace one must still apply Gram–Schmidt. This gives $(1,-1,0)$ and $(1,1,-2)$, so

$$P=\begin{pmatrix}1/\sqrt3&1/\sqrt2&1/\sqrt6\\1/\sqrt3&-1/\sqrt2&1/\sqrt6\\1/\sqrt3&0&-2/\sqrt6\end{pmatrix},\qquad P^{\mathsf T}SP=\operatorname{diag}(4,1,1).$$

4. Eigenvectors of a normal operator 10:31

Lemma 4.1. If $T$ is normal, then $\|T\alpha\|=\|T^*\alpha\|$ for all $\alpha$.

Proof. $\|T\alpha\|^2=\langle\alpha,T^*T\alpha\rangle=\langle\alpha,TT^*\alpha\rangle=\|T^*\alpha\|^2$. $\square$

Theorem 4.2. Let $T$ be normal and $c\in F$. Then $T\alpha=c\alpha$ if and only if $T^*\alpha=\bar c\,\alpha$.

Proof. The operator $T-cI$ has the adjoint $T^*-\bar cI$, and the two commute because $T$ and $T^*$ do. So $T-cI$ is normal, and Lemma 4.1 gives $\|(T-cI)\alpha\|=\|(T^*-\bar cI)\alpha\|$. One side vanishes exactly when the other does. $\square$

So a normal operator and its adjoint share their eigenvectors, with conjugate eigenvalues.

5. Triangular and normal means diagonal 18:07

Theorem 5.1. Let the matrix $A$ of $T$ in an orthonormal basis $(\alpha_1,\dots,\alpha_n)$ be upper triangular. Then $T$ is normal if and only if $A$ is diagonal.

Proof. Diagonal matrices commute with their conjugate transposes, which gives one direction. Let $T$ be normal. Upper triangularity gives $T\alpha_1=A_{11}\alpha_1$. By Theorem 4.2, $T^*\alpha_1=\overline{A_{11}}\alpha_1$. But the matrix of $T^*$ is $A^*$, so $T^*\alpha_1=\sum_j\overline{A_{1j}}\alpha_j$. Comparing, $A_{1j}=0$ for $j\gt1$. Now column $2$ of $A$ has only the entry $A_{22}$ left, so $T\alpha_2=A_{22}\alpha_2$, and the same argument clears the rest of row $2$. Continue row by row. $\square$

6. Schur's theorem 02:33

Theorem 6.1. Let $V$ be a finite-dimensional complex inner product space and $T$ an operator. Some orthonormal basis gives $T$ an upper triangular matrix.

Proof. Induct on $n$; $n=1$ is clear. The operator $T^*$ has a unit eigenvector $\alpha$, since the field is $\mathbb{C}$. Then $\operatorname{span}(\alpha)$ is $T^*$-invariant, so $W=\{\alpha\}^{\perp}$ is invariant under $(T^*)^*=T$ (Lemma 2.1). By induction $W$ has an orthonormal basis $\alpha_1,\dots,\alpha_{n-1}$ in which $T|_W$ is upper triangular. Append $\alpha$ as the last vector. The first $n-1$ columns of the matrix of $T$ come from $T|_W$ and have last entry $0$, and the last column is arbitrary. So the matrix is upper triangular. $\square$

The eigenvector is taken from $T^*$, not from $T$, so that it can be placed last. Chapter 24 obtained the same theorem by orthonormalizing a triangularizing basis.

Corollary 6.2 14:09. For every $A\in\mathbb{C}^{n\times n}$ there is a unitary $U$ with $U^{-1}AU$ upper triangular.

Proof. Apply the theorem to $X\mapsto AX$ on $\mathbb{C}^n$ and take the basis vectors as the columns of $U$. $\square$

7. The spectral theorem 21:47

Theorem 7.1. Let $T$ be a normal operator on a finite-dimensional complex inner product space, or a self-adjoint operator on a finite-dimensional real one. Let $c_1,\dots,c_k$ be its distinct eigenvalues, $W_j=\ker(T-c_jI)$, and $E_j$ the orthogonal projection on $W_j$. Then

  1. $W_i\perp W_j$ for $i\ne j$, and $V=W_1\oplus\dots\oplus W_k$;
  2. $I=E_1+\dots+E_k$, $E_iE_j=0$ for $i\ne j$, and $E_j^2=E_j=E_j^*$;
  3. $T=c_1E_1+\dots+c_kE_k$.

Proof. There is an orthonormal basis of eigenvectors: in the complex case by Theorems 6.1 and 5.1, in the real case by Theorem 3.1. Hence the $W_j$ span $V$. For orthogonality let $\alpha\in W_i$, $\beta\in W_j$, $i\ne j$. By Theorem 4.2, $T^*\beta=\overline{c_j}\beta$, so $c_i\langle\alpha,\beta\rangle=\langle T\alpha,\beta\rangle=\langle\alpha,T^*\beta\rangle=c_j\langle\alpha,\beta\rangle$. As $c_i\ne c_j$, $\langle\alpha,\beta\rangle=0$. So every $\alpha$ is uniquely $\alpha_1+\dots+\alpha_k$ with $\alpha_j\in W_j$, and orthogonality shows $\alpha_j=E_j\alpha$. This gives part 2 (orthogonal projections are self-adjoint). Applying $T$ to $\alpha=\sum_jE_j\alpha$ gives $T\alpha=\sum_jc_jE_j\alpha$. $\square$

The formula in part 3 is the spectral resolution of $T$, and $I=\sum E_j$ the corresponding resolution of the identity.

The converse. If $V$ has an orthonormal eigenbasis of $T$, then $T$ is normal, and over $\mathbb{R}$ self-adjoint (Chapter 24). So the theorem is a characterization in both cases.

8. Polynomials in a normal operator 30:44

Since $E_iE_j=\delta_{ij}E_j$ (where $\delta_{ij}$ is $1$ if $i=j$ and $0$ otherwise), $T^r=\sum_jc_j^rE_j$ for every $r\ge0$, and therefore for every polynomial $f$ over $F$:

$$f(T)=\sum_{j=1}^kf(c_j)\,E_j .$$

Corollary 8.1. Each $E_j$ is a polynomial in $T$: with the Lagrange polynomial

$$e_j(x)=\prod_{i\ne j}\frac{x-c_i}{c_j-c_i},\qquad e_j(c_i)=\delta_{ij},$$

one has $E_j=e_j(T)$. (For $k=1$ the empty product is $1$.)

On the running example. $c_1=4$, $c_2=1$, $e_1=(x-1)/3$ and $e_2=(4-x)/3$. With $J$ the matrix of all ones,

$$E_1=\frac13J,\qquad E_2=I-\frac13J,\qquad S=4E_1+E_2 .$$

Now the opening questions are answered: $S^{10}=4^{10}E_1+E_2$, and $R=2E_1+E_2=I+\tfrac13J$ satisfies $R^2=S$.

A complex normal example. $C=\begin{pmatrix}1&-1\\1&1\end{pmatrix}$ commutes with $C^{\mathsf T}$ and is neither symmetric nor unitary. Over $\mathbb{C}$ its eigenvalues are $1\pm i$, with orthogonal eigenvectors $(\pm i,1)$, and $$C=(1+i)\,\frac12\begin{pmatrix}1&i\\-i&1\end{pmatrix}+(1-i)\,\frac12\begin{pmatrix}1&-i\\i&1\end{pmatrix}.$$ Over $\mathbb{R}$ it has no eigenvector, so normality alone does not suffice there.

Exercises

  1. (Computation.) Find the spectral resolution of $A=\begin{pmatrix}2&1+i\\1-i&3\end{pmatrix}$.
  2. (Square roots.) Find all self-adjoint $R$ that are of the form $aE_1+bE_2$ and satisfy $R^2=S$.
  3. (Spectrum decides the type.) For a normal operator on a complex space show that it is self-adjoint exactly when all eigenvalues are real, and unitary exactly when all have modulus $1$.
  4. (Kernels.) For a normal $T$ show $\ker T=\ker T^*$ and $\ker T^2=\ker T$.
  5. (The adjoint as a polynomial.) For a normal operator on a complex space show that $T^*=f(T)$ for some polynomial $f$, and deduce that every operator commuting with $T$ commutes with $T^*$.
  6. (Boundary.) Show that $M=\begin{pmatrix}1&1\\0&2\end{pmatrix}$ is diagonalizable but has no orthonormal basis of eigenvectors.
Fully worked solutions

  1. $\det(xI-A)=x^2-5x+4$, so $c=1,4$. Lagrange gives $E_{(1)}=(4I-A)/3$ and $E_{(4)}=(A-I)/3$: $$E_{(1)}=\frac13\begin{pmatrix}2&-1-i\\-1+i&1\end{pmatrix},\qquad E_{(4)}=\frac13\begin{pmatrix}1&1+i\\1-i&2\end{pmatrix},$$ and $A=E_{(1)}+4E_{(4)}$.

  2. $R^2=a^2E_1+b^2E_2$. Comparing with $4E_1+E_2$ after multiplying by $E_1$ and by $E_2$ gives $a=\pm2$, $b=\pm1$. All four are self-adjoint because $a,b$ are real. Only $a=2,b=1$ has all eigenvalues positive. (There are further square roots not of this form, since $E_2$ has rank $2$.)

  3. By Theorem 7.1, $T=\sum c_jE_j$ and $T^*=\sum\overline{c_j}E_j$. So $T^*=T$ exactly when $\sum(\overline{c_j}-c_j)E_j=0$; multiplying by $E_i$ shows $\overline{c_i}=c_i$. Similarly $T^*T=\sum|c_j|^2E_j$ equals $I=\sum E_j$ exactly when every $|c_j|=1$, and in finite dimension $T^*T=I$ implies unitarity.

  4. The first equality is Lemma 4.1. For the second, $\ker T\subseteq\ker T^2$ is clear. If $T^2\alpha=0$, then $\beta=T\alpha$ lies in $\ker T=\ker T^*$. So $\|\beta\|^2=\langle T\alpha,\beta\rangle=\langle\alpha,T^*\beta\rangle=0$.

  5. Take $f=\sum_j\overline{c_j}\,e_j$. Then $f(c_i)=\overline{c_i}$, so $f(T)=\sum\overline{c_i}E_i=T^*$. If $UT=TU$, then $U$ commutes with every polynomial in $T$, in particular with $T^*$.

  6. The eigenvalues $1,2$ are distinct, so $M$ is diagonalizable. The eigenspaces are spanned by $(1,0)$ and $(1,1)$, whose inner product is $1$. Every eigenvector is a multiple of one of them, so no two eigenvectors form an orthonormal basis. Consistently, $MM^{\mathsf T}\ne M^{\mathsf T}M$.

"""Chapter 25 laboratory: spectral resolutions.

Exact arithmetic.  Rational matrices use fractions.Fraction.  Complex
matrices with integer or half-integer entries use Python complex, which is
exact for these values.  The general theorems are proved in the chapter;
this file checks the printed instances.
"""
from fractions import Fraction as Fr

import numpy as np


def mul(a, b):
    return [[sum(a[i][k] * b[k][j] for k in range(len(b)))
             for j in range(len(b[0]))] for i in range(len(a))]


def comb(c, a, d, b):
    return [[c * x + d * y for x, y in zip(r, s)] for r, s in zip(a, b)]


def running_example():
    n = range(3)
    eye = [[Fr(int(i == j)) for j in n] for i in n]
    s = [[Fr(2 if i == j else 1) for j in n] for i in n]
    e1 = [[Fr(1, 3) for j in n] for i in n]
    e2 = comb(1, eye, -1, e1)
    zero = [[0] * 3 for i in n]
    assert mul(e1, e1) == e1 and mul(e2, e2) == e2
    assert mul(e1, e2) == zero
    assert comb(4, e1, 1, e2) == s
    assert comb(Fr(1, 3), s, Fr(-1, 3), eye) == e1
    assert comb(Fr(-1, 3), s, Fr(4, 3), eye) == e2
    power = eye
    for _ in range(10):
        power = mul(power, s)
    assert power == comb(4 ** 10, e1, 1, e2)
    for a in (2, -2):
        for b in (1, -1):
            r = comb(a, e1, b, e2)
            assert mul(r, r) == s
    assert comb(2, e1, 1, e2) == comb(1, eye, 1, e1)
    u, w = [1, -1, 0], [1, 0, -1]
    dot = sum(x * y for x, y in zip(u, w))
    v = [y - Fr(dot, 2) * x for x, y in zip(u, w)]
    assert dot == 1 and [2 * x for x in v] == [1, 1, -2]
    for x in ([1, 1, 1], u, [1, 1, -2]):
        lam = 4 if x == [1, 1, 1] else 1
        assert [sum(p * q for p, q in zip(row, x)) for row in s] == [
            lam * t for t in x]
    print('S = 4 E1 + E2; S^10 entry (1,1) =', power[0][0])


def complex_examples():
    c = np.array([[1, -1], [1, 1]])
    assert np.array_equal(c @ c.T, c.T @ c)
    p = np.array([[1, 1j], [-1j, 1]]) / 2
    q = p.conj()
    assert np.array_equal((1 + 1j) * p + (1 - 1j) * q, c)
    assert np.array_equal(p @ p, p) and np.array_equal(p @ q, 0 * p)
    for sign in (1, -1):
        v = np.array([sign * 1j, 1])
        assert np.array_equal(c @ v, (1 + sign * 1j) * v)
    a = np.array([[2, 1 + 1j], [1 - 1j, 3]])
    eye = np.eye(2)
    e1, e4 = (4 * eye - a) / 3, (a - eye) / 3
    assert np.allclose(e1 + 4 * e4, a)
    assert np.allclose(e1 @ e1, e1) and np.allclose(e1 @ e4, 0)
    assert np.allclose(3 * e1, [[2, -1 - 1j], [-1 + 1j, 1]])
    m = np.array([[1, 1], [0, 2]])
    assert not np.array_equal(m @ m.T, m.T @ m)
    assert np.array_equal(m @ [1, 1], [2, 2])
    x = np.array([0, 1])
    assert np.vdot(m @ x, m @ x) != np.vdot(m.T @ x, m.T @ x)
    assert np.vdot(c @ x, c @ x) == np.vdot(c.T @ x, c.T @ x)
    print('complex resolutions and normality tests verified')


def main():
    running_example()
    complex_examples()
    print('all chapter 25 checks passed')


if __name__ == '__main__':
    main()
