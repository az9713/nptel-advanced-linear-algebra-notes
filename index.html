Advanced Linear Algebra

Spaces, operators, and their canonical decompositions

A matrix is a table of numbers; a linear operator is what the table represents once a basis is chosen. This study edition follows that distinction from row reduction to the singular value decomposition: which facts belong to the matrix, which to the operator, which depend on the field, and which need an inner product.

The source course is NPTEL Advanced Linear Algebra, IIT Roorkee, taught by Prof. Premananda Bera. The edition groups 60 teaching recordings into 26 chapters. The supplied playlist has a promo and 59 lectures; Lecture 44 is absent from it and was taken from the official course outline.

Original playlist · Official course · Recording map · Study routes · Interactive laboratory

How to read this edition

The intended reader can compute with matrices and wants proof-level command of the abstract theory. Each chapter opens with a concrete problem, defines its terms before use, states hypotheses with each theorem, proves the central results, and tests them on a running example. Six exercises with full solutions and an executable Python laboratory close each chapter.

The recordings determine the topic order. Proofs, worked examples, code, and solutions are independently written. A timestamp locates a related discussion; it does not attribute every argument in that section to the lecturer. Captions carry no board writing, so the numerical examples are original constructions. References and evidence limits state what was and was not checked.
